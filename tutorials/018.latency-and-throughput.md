# 014. Latency and Throughput

## Overview
Understanding latency and throughput is essential for capacity planning and performance optimization.

## Key Metrics
- **Latency**: Time from request to response (ms). Focus on percentiles (p50, p95, p99).
- **Throughput**: Requests per second (RPS) the system can handle.
- **Bandwidth**: Amount of data transferred per second.

## Percentiles Explained
- **p50 (Median)**: 50% of requests complete within this time.
- **p95**: 95% of requests complete within this time. Good for SLA targets.
- **p99**: 99% of requests complete within this time. Catches outliers.

## Optimization Techniques
- Async processing.
- Connection pooling.
- Batching.
- Reducing round trips.
