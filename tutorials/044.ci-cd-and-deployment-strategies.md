# 038. CI/CD and Deployment Strategies

## Overview
Automated testing and deployment strategies ensuring zero downtime and rapid iteration.

## Deployment Strategies
- **Blue-Green**: Switch traffic between two identical production environments.
- **Canary**: Roll out changes to a small subset of users first.
- **Rolling Update**: Incrementally update servers in the pool.

## CI/CD Pipeline
Build -> Test -> Security Scan -> Deploy.
