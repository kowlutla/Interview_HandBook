# 027. Change Data Capture (CDC)

## Overview
CDC tracks and captures database changes (inserts, updates, deletes) for downstream processing.

## How It Works
- Database logs (WAL in Postgres, binlog in MySQL) are monitored.
- Changes are captured and published to message queue or directly to consumers.

## Popular Tools
- **Debezium**: Open-source CDC platform, integrates with Kafka.
- **AWS DMS**: Managed CDC service.
- **Maxwell**: MySQL binlog parser.

## Use Cases
- Sync database to Elasticsearch for search.
- Replicate data to data warehouse.
- Update caches.
