# 004. Architectural Styles

## Overview
Choosing the right architectural style is crucial for long-term maintainability and performance.

## Common Styles
- **Monolithic**: Single codebase, easy to deploy initially, hard to scale as it grows.
- **Microservices**: Decomposed into small, independent services. Enables independent scaling, but adds operational complexity.
- **Event-Driven**: Systems communicate via events. Highly scalable, asynchronous.
- **Serverless**: Event-driven execution where the cloud provider manages infrastructure.
- **Peer-to-Peer (P2P)**: Decentralized architecture where nodes act as both clients and servers.
