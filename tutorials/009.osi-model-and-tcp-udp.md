# 006.5. OSI Model, TCP, and UDP

## Overview
Understanding network layers and transport protocols underlying distributed systems communication.

## OSI 7-Layer Model
1. Physical -> 2. Data Link -> 3. Network (IP) -> 4. Transport (TCP/UDP) -> 5. Session -> 6. Presentation -> 7. Application (HTTP)

## TCP vs. UDP
- **TCP (Transmission Control Protocol)**: Connection-oriented, reliable, ordered delivery, flow control, congestion control (HTTP/gRPC/WebSockets).
- **UDP (User Datagram Protocol)**: Connectionless, unreliable, fast, no overhead (DNS, WebRTC streaming, gaming).
