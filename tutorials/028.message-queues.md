# 023. Message Queues

## Overview
Message queues decouple producers and consumers, enabling asynchronous communication and resilience.

## Popular Solutions
- **RabbitMQ**: Flexible routing, supports multiple protocols (AMQP, MQTT).
- **Apache Kafka**: High-throughput, durable, log-based. Great for event streaming.
- **AWS SQS**: Fully managed, simple queue service.
- **ActiveMQ**: Enterprise-grade, JMS support.

## Messaging Patterns
- **Point-to-Point**: One producer, one consumer. Message processed once.
- **Pub/Sub**: One producer, multiple consumers. Each subscriber gets a copy.

## Key Concepts
- **Message Persistence**: Durability guarantees.
- **Delivery Semantics**: At-least-once, exactly-once, at-most-once.
- **Dead Letter Queue**: For failed messages after retries.
