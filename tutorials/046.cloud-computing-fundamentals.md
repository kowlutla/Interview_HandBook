# 040. Cloud Computing Fundamentals

## Overview
Understanding cloud computing primitives (IaaS, PaaS, SaaS, FaaS) and architectural trade-offs.

## Service Models
- **IaaS (Infrastructure as Service)**: VMs, storage, networking (AWS EC2, GCP Compute Engine).
- **PaaS (Platform as Service)**: Managed runtime environments (AWS Elastic Beanstalk, Heroku).
- **SaaS (Software as Service)**: Fully managed software applications (Gmail, Salesforce).
- **FaaS (Function as Service / Serverless)**: Event-driven code execution without server management (AWS Lambda).

## Cost vs Performance
- Pay-as-you-go pricing, provisioned concurrency, and reserved instances.
