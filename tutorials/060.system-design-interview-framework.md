# 054. System Design Interview Framework

## Overview
A structured 45-minute framework to ace system design interviews.

## Step-by-Step Breakdown
1. **Clarify Requirements (5 mins)**: Functional, non-functional (scale, latency).
2. **Back-of-the-Envelope Estimation (5 mins)**: QPS, storage, bandwidth.
3. **High-Level Design (15 mins)**: Core components, API endpoints, data flow.
4. **Deep Dive & Bottlenecks (15 mins)**: Sharding, caching, fault tolerance, scaling bottlenecks.
5. **Wrap Up & Trade-offs (5 mins)**: Summary, pros/cons, monitoring.
