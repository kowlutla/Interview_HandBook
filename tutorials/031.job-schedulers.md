# 026. Job Schedulers

## Overview
Job schedulers automate task execution at specified times or intervals.

## Types
- **Cron**: Unix-based, simple time-based scheduling.
- **Distributed Schedulers**: Handle scheduling across multiple nodes.

## Distributed Scheduler Patterns
- **Leader Election**: Only one node executes job at a time.
- **Work Queue**: Jobs queued, picked up by available workers.
- **Cron with Lock**: Prevents duplicate execution using distributed locks.

## Use Cases
- Report generation.
- Data synchronization.
- Cleanup tasks.
