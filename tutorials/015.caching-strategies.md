# 011. Caching Strategies

## Overview
Caching stores frequently accessed data in fast storage to reduce latency and load on backend systems.

## Common Strategies
- **Cache-Aside (Lazy Loading)**: App checks cache first; on miss, loads from DB and populates cache.
- **Write-Through**: Write to cache and DB simultaneously. Low read latency, higher write latency.
- **Write-Back (Write-Behind)**: Write to cache first, then asynchronously write to DB. Risk of data loss.
- **Refresh-Ahead**: Proactively refresh cache entries before expiration based on access patterns.
