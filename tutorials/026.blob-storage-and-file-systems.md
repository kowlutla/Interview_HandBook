# 021. Blob Storage and File Systems

## Overview
Blob (Binary Large Object) storage is designed for unstructured data like images, videos, and documents.

## Object Storage (S3-style)
- **S3 (AWS)**, **GCS**, **Azure Blob**: Highly durable, tiered storage, pay-per-use.
- Objects stored with unique keys, metadata, and access controls.

## Distributed File Systems
- **HDFS**: Hadoop Distributed File System, for batch processing.
- **GlusterFS**, **Ceph**: Scale-out file systems.

## Use Cases
- Media storage (images, videos).
- Backups and archives.
- Static website hosting.
