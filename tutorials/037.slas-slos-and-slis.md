# 031.5. SLAs, SLOs, and SLIs

## Overview
Formalizing system reliability expectations using Site Reliability Engineering (SRE) metrics.

## Key Definitions
- **SLI (Service Level Indicator)**: Quantitative metric of service performance (e.g., request latency, error rate).
- **SLO (Service Level Objective)**: Target reliability value set for an SLI over a time window (e.g., 99.9% of requests < 200ms).
- **SLA (Service Level Agreement)**: Business contract with customers guaranteeing an SLO, backed by financial penalties for breaches.
