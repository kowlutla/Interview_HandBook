# 029. Circuit Breakers and Bulkheads

## Overview
Patterns to prevent cascading failures in distributed systems.

## Circuit Breaker
- **Closed**: Normal operation; requests pass through.
- **Open**: Failures exceed threshold; requests fail fast without calling backend.
- **Half-Open**: Test requests allowed; if successful, resets to Closed.

## Bulkhead
- Isolates resources (threads, memory, connections) so a failure in one area doesn't exhaust the whole system.
- Analogy: Watertight compartments in a ship.
