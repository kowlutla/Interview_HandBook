# 009. Proxies and API Gateways

## Overview
Proxies and API gateways are intermediate layers that manage traffic, security, and routing.

## Proxy Types
- **Forward Proxy**: Sits between client and internet. Used for caching, filtering, anonymity.
- **Reverse Proxy**: Sits between internet and servers. Hides backend infrastructure, load balancing, SSL termination.

## API Gateway
A unified entry point for microservices, handling:
- Request routing.
- Authentication/Authorization.
- Rate limiting.
- Protocol translation (REST to gRPC).
