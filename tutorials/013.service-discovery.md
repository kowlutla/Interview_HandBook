# 009.5. Service Discovery

## Overview
How microservices locate one another dynamically in ephemeral cloud environments.

## Mechanisms
- **Client-Side Discovery**: Client queries service registry (e.g., Consul, Eureka) and load balances directly.
- **Server-Side Discovery**: Client sends request to Load Balancer / API Gateway, which queries registry and routes (e.g., AWS ALB, Kubernetes Ingress/DNS).
