# 034. Search Systems

## Overview
Full-text search engines provide fast, relevant search across large document collections.

## Core Concepts
- **Inverted Index**: Maps words to document locations, similar to a book index.
- **Tokenization**: Breaking text into words/tokens.
- **Ranking (Relevance)**: TF-IDF, BM25 algorithms to score document relevance.

## Popular Tools
- **Elasticsearch**: Distributed, RESTful search engine.
- **Apache Solr**: Mature, highly scalable search platform.
- **Typesense / Meilisearch**: Fast, lightweight alternatives.
