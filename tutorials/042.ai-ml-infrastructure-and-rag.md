# 036. AI/ML Infrastructure and RAG

## Overview
Designing systems to integrate Large Language Models (LLMs) and machine learning workflows.

## Retrieval-Augmented Generation (RAG)
- Combines external knowledge retrieval with LLM generation.
- **Vector Databases**: Pinecone, Milvus, Qdrant store embeddings for semantic search.

## ML Pipeline
- Data ingestion -> Feature store -> Model training -> Model serving (inference).
