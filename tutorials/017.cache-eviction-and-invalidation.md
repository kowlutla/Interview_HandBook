# 013. Cache Eviction and Invalidation

## Overview
When cache reaches capacity, eviction policies determine which items to remove. Invalidation ensures stale data is removed.

## Eviction Policies
- **LRU (Least Recently Used)**: Evicts least recently accessed items.
- **LFU (Least Frequently Used)**: Evicts least frequently accessed items.
- **FIFO (First In, First Out)**: Evicts oldest items regardless of access.
- **TTL (Time To Live)**: Items automatically expire after a set time.

## Invalidation Strategies
- **Immediate**: Delete specific cache entries on data change.
- **Lazy Expiration**: Rely on TTL; simpler but may serve stale data temporarily.
- **Write-Through Invalidation**: Update cache on writes (if using write-through).
