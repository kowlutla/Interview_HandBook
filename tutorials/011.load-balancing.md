# 008. Load Balancing

## Overview
Load balancers distribute incoming traffic across multiple servers to ensure no single server is overwhelmed.

## Types
- **Layer 4 (Transport)**: Routes based on IP + TCP/UDP port. Faster, less context.
- **Layer 7 (Application)**: Routes based on URL, headers, cookies. Smarter but more overhead.

## Algorithms
- **Round Robin**: Sequentially cycles through servers.
- **Least Connections**: Routes to server with fewest active connections.
- **Weighted**: Assigns weight based on server capacity.
- **IP Hash**: Routes based on client IP for session persistence.

## Health Checks
Load balancers periodically check server health and remove unhealthy servers from the pool.
