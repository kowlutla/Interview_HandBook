# 043. Infrastructure as Code (IaC)

## Overview
Managing and provisioning cloud infrastructure through declarative configuration files rather than manual UI actions.

## Key Tools
- **Terraform / OpenTofu**: Declarative cloud provisioning.
- **AWS CloudFormation**: Native AWS IaC.
- **Pulumi**: Use general-purpose programming languages for IaC.

## Principles
- Version control infrastructure.
- Idempotency.
- Immutable infrastructure.
