# 007. Content Delivery Networks (CDN)

## Overview
CDNs distribute content globally, serving static assets from edge locations closest to users.

## How CDN Works
1. User requests static content.
2. CDN checks cache at edge location.
3. If miss, CDN fetches from origin and caches.

## Benefits
- Reduced latency.
- Offload origin server.
- DDoS protection (some providers).

## CDN Providers
Cloudflare, AWS CloudFront, Akamai, Fastly.
