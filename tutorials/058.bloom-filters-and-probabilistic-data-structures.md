# 052. Bloom Filters & Probabilistic Data Structures

## Overview
Using memory-efficient probabilistic data structures to test set membership with trade-offs on false positives.

## Bloom Filter
- Space-efficient data structure to test if an element is *definitely not* in a set or *probably* in a set.
- **False Positives**: Possible (item reported present when absent).
- **False Negatives**: Impossible (if reported absent, it is definitely absent).

## Use Cases
- Preventing cache stampedes (checking if key exists before querying DB).
- Database query optimization (skipping disk blocks without data).
