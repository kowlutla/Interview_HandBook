# 031. Observability, Logging, and Metrics

## Overview
Observability lets you understand the internal state of a system through its outputs.

## The Three Pillars
- **Logs**: Discrete events with timestamps (Elasticsearch, Fluentd, Kibana).
- **Metrics**: Aggregated numerical data (Prometheus, Grafana, Datadog).
- **Traces**: End-to-end request path across microservices.

## Best Practices
- Structured logging (JSON format).
- Set meaningful alerts for SLO breaches.
- Avoid log spamming.
