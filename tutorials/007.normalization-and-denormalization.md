# 005.5. Normalization and Denormalization

## Overview
Structuring relational database schemas to balance data integrity with query performance.

## Normalization (1NF, 2NF, 3NF)
- Eliminates data redundancy.
- Minimizes update anomalies.
- Requires more table joins, increasing read latency.

## Denormalization
- Deliberately introduces redundancy by combining tables.
- Optimizes for read-heavy workloads by eliminating expensive joins.
- Requires application-level or trigger-based synchronization on writes.
