# 017. Database Indexing and Storage

## Overview
Indexes accelerate data retrieval. Storage engines determine how data is physically organized.

## Index Types
- **B-Tree**: Default for most databases. O(log n) lookups, sorted range queries.
- **Hash Index**: O(1) lookups, exact matches only.
- **Full-Text Index**: For text search, tokenizes content.
- **Composite Index**: Multiple columns, order matters.

## Storage Engines
- **InnoDB (MySQL)**: Row-oriented, B-Tree indexes, ACID compliant.
- **WAL (Write-Ahead Logging)**: Append-only logs for durability.

## Index Trade-offs
- Faster reads, slower writes (more to update).
- Additional storage space.
