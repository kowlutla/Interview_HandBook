# 045. Client-Side Storage and Offline-First

## Overview
Designing web applications that work reliably offline and persist state locally.

## Storage Mechanisms
- **LocalStorage / SessionStorage**: Key-value strings (sync, ~5MB limit).
- **IndexedDB**: Structured transactional database in the browser.
- **Cache API**: Programmatic cache for network requests (Service Workers).

## Offline-First Architecture
- Service workers intercept network requests.
- Background sync for pending mutations when connectivity returns.
