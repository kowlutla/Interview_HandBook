# 018. Database Replication

## Overview
Replication copies data across multiple database instances for availability and read scalability.

## Replication Methods
- **Synchronous**: Waits for all replicas to confirm write before returning. Strong consistency but higher latency.
- **Asynchronous**: Returns immediately after primary write. Lower latency but eventual consistency.

## Topologies
- **Master-Slave**: Master handles writes, slaves replicate for reads. Simple, scales reads.
- **Multi-Master**: Multiple nodes accept writes. Complex conflict resolution.
- **Circular**: Each node replicates to the next. No single point of failure.

## Use Cases
- Read replicas for scaling read-heavy workloads.
- Geographic distribution for lower latency.
- Failover for high availability.
