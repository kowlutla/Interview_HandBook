# 033. Disaster Recovery and Backup

## Overview
Preparing for catastrophic failures (datacenter outages, data corruption).

## Key Metrics
- **RPO (Recovery Point Objective)**: Maximum acceptable data loss duration.
- **RTO (Recovery Time Objective)**: Maximum acceptable downtime duration.

## Backup Strategies
- **Full Backup**: Complete copy of data.
- **Incremental Backup**: Changes since last backup.
- **Differential Backup**: Changes since last full backup.

## Multi-Region Failover
Active-Passive or Active-Active setups across geographic regions.
