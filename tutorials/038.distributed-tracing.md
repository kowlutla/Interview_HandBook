# 032. Distributed Tracing

## Overview
Tracing requests as they traverse multiple distributed services.

## Key Concepts
- **Trace**: Entire journey of a request.
- **Span**: Individual operation within a trace.
- **Trace Context**: Headers passed between services to link spans.

## Tools
- **OpenTelemetry**: Standard for collecting telemetry data.
- **Jaeger**, **Zipkin**: Trace visualization backends.
