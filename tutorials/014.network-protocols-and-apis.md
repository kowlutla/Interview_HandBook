# 010. Network Protocols and APIs

## Overview
Understanding different API styles and protocols helps choose the right communication pattern.

## API Styles
- **REST**: Resource-based, uses HTTP methods. Universally understood.
- **GraphQL**: Query language for APIs. Clients specify exactly what they need.
- **gRPC**: High-performance, uses Protocol Buffers. Great for inter-service communication.
- **WebSockets**: Full-duplex communication over a single TCP connection.
- **Server-Sent Events (SSE)**: One-way server-to-client streaming over HTTP.

## Key Considerations
- Payload size vs. readability.
- Client needs (mobile vs. web).
- Team expertise.
