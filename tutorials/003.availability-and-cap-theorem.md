# 003. Availability and CAP Theorem

## Overview
Reliability requires high availability. The CAP theorem helps guide design choices regarding data consistency.

## CAP Theorem
- **Consistency**: Every read receives the most recent write or an error.
- **Availability**: Every request receives a (non-error) response, without the guarantee that it contains the most recent write.
- **Partition Tolerance**: The system continues to operate despite an arbitrary number of messages being dropped (or delayed) by the network between nodes.

## Trade-offs
In the presence of a network partition, you must choose either Consistency or Availability (CP or AP).

## Reliability Metrics
- **SLIs/SLOs/SLAs**: Service Level Indicators/Objectives/Agreements define reliability expectations.
