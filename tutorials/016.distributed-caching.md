# 012. Distributed Caching

## Overview
Distributed caches span multiple nodes, providing scalability and high availability.

## Popular Solutions
- **Redis**: In-memory data store, supports strings, lists, sets, sorted sets, pub/sub.
- **Memcached**: Simple key-value store, pure memory, no persistence.

## Clustering Approaches
- **Sharding**: Distribute keys across nodes using consistent hashing.
- **Replication**: Master-replica setup for read scalability and fault tolerance.

## Considerations
- Memory management (eviction policies).
- Network latency between nodes.
- Persistence needs (Redis AOF/RDB).
