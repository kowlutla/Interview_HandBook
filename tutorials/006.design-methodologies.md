# 005. Design Methodologies

## Overview
Methodologies ensure consistency, maintainability, and clarity in complex designs.

## Key Methodologies
- **Domain-Driven Design (DDD)**: Aligning software structure with business domains.
- **CQRS (Command Query Responsibility Segregation)**: Separating read and write models to optimize performance.
- **Clean Architecture / Hexagonal Architecture**: Focusing on separating business logic from infrastructure (DBs, UI).
