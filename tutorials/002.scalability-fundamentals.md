# 002. Scalability Fundamentals

## Overview
Scalability is the ability of a system to handle increased load by adding resources.

## Key Concepts
- **Vertical Scaling (Scaling Up)**: Adding more power (CPU, RAM) to existing machines. Limited by hardware ceiling.
- **Horizontal Scaling (Scaling Out)**: Adding more machines to the pool. More flexible, but increases complexity (networking, data consistency).

## Important Metrics
- **Latency**: Time taken to process a request.
- **Throughput**: Number of requests processed per unit of time.

## Key Principles
- Minimize state (Stateless services).
- Build for failure (redundancy).
