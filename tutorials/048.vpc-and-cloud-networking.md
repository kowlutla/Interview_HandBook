# 042. VPC and Cloud Networking

## Overview
Configuring virtual private clouds, subnets, and secure network boundaries in the cloud.

## Key Concepts
- **VPC (Virtual Private Cloud)**: Isolated private network in public cloud.
- **Subnets**: Public (exposed to internet via Internet Gateway) vs. Private (internal services).
- **NAT Gateway / NAT Instance**: Allows private subnets to reach the internet securely.
- **VPC Peering & Transit Gateway**: Connecting multiple VPCs together.
