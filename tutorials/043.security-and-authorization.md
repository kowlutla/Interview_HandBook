# 037. Security and Authorization

## Overview
Securing APIs, data, and infrastructure against threats.

## Authentication vs Authorization
- **Authentication (AuthN)**: Who are you? (OAuth2, OIDC, JWT).
- **Authorization (AuthZ)**: What can you do? (RBAC, ABAC).

## Encryption
- **At Rest**: Encrypting databases and file storage (AES-256).
- **In Transit**: TLS/SSL certificates, HTTPS.
