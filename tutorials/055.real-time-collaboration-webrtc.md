# 049. Real-Time Collaboration & WebRTC

## Overview
Architecting low-latency peer-to-peer and real-time collaborative applications.

## WebRTC Architecture
- **STUN / TURN Servers**: Help peers discover public IPs and relay traffic behind symmetric NATs.
- **SFU (Selective Forwarding Unit)** vs. **MCU (Multipoint Control Unit)**: Topologies for video conferencing scalability.

## Real-Time Collaboration
- WebSockets for signaling and state sync.
- Presence detection and heartbeat mechanisms.
