# 035. Analytics and Data Warehousing

## Overview
OLAP (Online Analytical Processing) systems optimized for complex queries and aggregations over large datasets.

## Data Warehouses
- **Snowflake**, **Google BigQuery**, **Amazon Redshift**: Columnar storage, massively parallel processing (MPP).

## ETL / ELT
- **Extract, Transform, Load**: Traditional data pipeline.
- **Extract, Load, Transform**: Modern approach loading raw data into warehouse first.
