# 039. System Design Interview Framework

## Overview
A structured approach to tackling system design interviews successfully.

## The 4-Step Framework
1. **Step 1: Understand the Problem & Establish Design Scope (5-10 mins)**
   - Clarify functional requirements (features).
   - Clarify non-functional requirements (scale, latency, availability).
   - Back-of-the-envelope estimations (DAU, QPS, storage).

2. **Step 2: Propose High-Level Design (10-15 mins)**
   - Core components (clients, load balancer, API gateway, services, DB, cache).
   - Data flow and API endpoints.

3. **Step 3: Detailed Design (10-15 mins)**
   - Dive deep into specific components (e.g., sharding strategy, caching policy, database schema).
   - Address bottlenecks and edge cases.

4. **Step 4: Wrap Up / Trade-offs (3-5 mins)**
   - Discuss trade-offs and alternatives.
   - Monitoring, logging, and failure handling.
