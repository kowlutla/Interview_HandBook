# 044. Browser Performance and Rendering

## Overview
Understanding client-side performance, browser rendering pipelines, and Core Web Vitals.

## Rendering Pipeline
1. **DOM & CSSOM Construction**: Parsing HTML/CSS.
2. **Layout (Reflow)**: Calculating exact positions and sizes.
3. **Paint**: Filling pixels onto layers.
4. **Compositing**: Drawing layers to screen.

## Core Web Vitals
- **LCP (Largest Contentful Paint)**: Loading performance (< 2.5s).
- **INP (Interaction to Next Paint)**: Interactivity / responsiveness (< 200ms).
- **CLS (Cumulative Layout Shift)**: Visual stability (< 0.1).
