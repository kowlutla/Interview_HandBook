# 025. Stream Processing

## Overview
Processing data in real-time as it flows through the system, rather than in batches.

## Lambda Architecture
- **Speed Layer**: Real-time processing (e.g., Spark Streaming, Flink).
- **Batch Layer**: Batch processing for accuracy.
- **Serving Layer**: Merges results from both layers.

## Kappa Architecture
- Simplifies Lambda by treating everything as streams.
- Uses a streaming system (e.g., Kafka) for both real-time and batch.

## Use Cases
- Real-time analytics.
- Fraud detection.
- Monitoring and alerting.
