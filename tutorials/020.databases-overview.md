# 016. Databases Overview

## Overview
Choosing the right database is foundational to system design.

## SQL vs NoSQL
- **SQL (Relational)**: Structured data, ACID transactions, fixed schema. Examples: PostgreSQL, MySQL.
- **NoSQL**: Flexible schema, horizontal scaling, eventual consistency. Types: Key-Value, Document, Column, Graph.

## CAP Theorem in Databases
- **CP**: Consistent during partitions (e.g., HBase, MongoDB).
- **AP**: Available during partitions (e.g., Cassandra, DynamoDB).

## ACID Properties
- **Atomicity**: All or nothing.
- **Consistency**: Valid state to valid state.
- **Isolation**: Concurrent transactions don't interfere.
- **Durability**: Committed data survives failures.

## BASE Model
- **Basically Available**: System guarantees availability.
- **Soft State**: State may change over time.
- **Eventual Consistency**: System will become consistent eventually.
