# 024. Event-Driven Architecture

## Overview
Systems communicate through events, enabling loose coupling and scalability.

## Core Concepts
- **Event Producer**: Emits events when something happens.
- **Event Consumer**: Reacts to events.
- **Event Broker**: Middleman routing events (Kafka, RabbitMQ).

## Event Sourcing
- Store state as sequence of events, not current state.
- Enables full audit trail, temporal queries, replay.

## CQRS (Command Query Responsibility Segregation)
- Separate read and write models.
- Write to event store; read from optimized read models.

## Benefits
- Loose coupling.
- Scalability.
- Auditability.
