# 030. Leader Election and Coordination

## Overview
Coordinating multiple nodes in a distributed system to avoid split-brain and manage tasks.

## Algorithms & Tools
- **Raft / Paxos**: Consensus algorithms for agreeing on state across nodes.
- **ZooKeeper / Etcd**: Distributed coordination services providing locks and leader election.

## Distributed Locks
- Ensures only one node performs a critical operation at a time.
- Implemented via Redis (Redlock) or Etcd.
