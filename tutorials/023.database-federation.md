# 018.5. Database Federation

## Overview
Splitting databases by function (federation) to scale read/write operations across distinct datasets.

## Concept
- Instead of a single monolithic database containing users, products, and orders, split into separate databases: `User_DB`, `Product_DB`, `Order_DB`.
- Reduces contention and read/write load on individual database instances.
- Unlike sharding (which splits the *same* table across nodes), federation splits *different* tables/domains.
