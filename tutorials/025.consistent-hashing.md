# 020. Consistent Hashing

## Overview
Consistent hashing minimizes data redistribution when adding or removing nodes.

## How It Works
- Keys and nodes mapped to a hash ring.
- Key stored on first node clockwise from its hash position.
- Only neighboring keys need remapping when nodes join/leave.

## Virtual Nodes
- Each physical node represented by multiple virtual nodes on the ring.
- Improves load distribution and handles heterogeneous node capacities.

## Benefits
- Scalability: Add/remove nodes with minimal data movement.
- Fault tolerance: Redistributes load gracefully.
