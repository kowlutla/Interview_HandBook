# 027. Design Google Maps Routing and Navigation

## 1. Requirements
- Compute optimal driving/walking routes between two geographic points.
- Real-time turn-by-turn navigation and traffic rerouting.

## 2. Architecture
- **Graph Representation**: Map modeled as a weighted graph (nodes = intersections, edges = roads with travel time weights).
- **Routing Algorithms**: Contraction Hierarchies (CH) and Dijkstra/A* algorithms optimized for fast pathfinding.
- **Traffic Layer**: Real-time telemetry speed ingestion updating edge weights.
