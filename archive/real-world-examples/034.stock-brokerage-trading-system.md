# 034. Design a Stock Brokerage Trading System (Robinhood / NASDAQ)

## 1. Requirements
- Ultra-low latency order matching engine (microseconds).
- High throughput order book processing.

## 2. Architecture
- **Matching Engine**: In-memory priority queues matching buy and sell limit orders.
- **Event Sourcing**: All orders persisted to append-only logs for auditability and crash recovery.
