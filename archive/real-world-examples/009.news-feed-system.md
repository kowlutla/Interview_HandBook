# 009. Design a News Feed System (Twitter / Facebook Feed)

## 1. Requirements
- Post a status update and see friends' updates in a chronological/algorithmic feed.
- Low latency feed generation (< 200ms).

## 2. Core Architecture: Fan-out Models
- **Fan-out on write (Push)**: Posts are pushed to all followers' cache timelines immediately. Great for reads, bad for celebrity accounts (million followers).
- **Fan-out on read (Pull)**: Posts stored in user's table; feed pulled and merged on read. Great for writes/celebrities, slow reads.
- **Hybrid approach**: Push for regular users, Pull for celebrities.
