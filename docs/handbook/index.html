Handbook

System Design Fundamentals

A complete, ordered handbook for high-level design interviews. Every component (CDN, load balancer, cache, queue, search, object store and more) gets a chapter of its own, explained in plain language with diagrams, worked numbers, failure modes and interview questions. Microservices have their own module.

How to read this Go in order the first time: each chapter ends with a Connects to line that names what it builds on and what comes next. Later, use the sidebar filter to jump to a topic. Greyed-out chapters are planned and not written yet.
