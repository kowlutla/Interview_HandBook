# 018. Design an Image Sharing Service (Instagram / Flickr)

## 1. Requirements
- Upload high-res images, apply filters, and view feeds.
- Fast image loading across mobile and web clients.

## 2. Architecture
- Client uploads image -> API Gateway -> S3 Object Storage.
- Asynchronous worker resizes images into thumbnail, medium, and full resolution.
- Metadata stored in SQL/NoSQL DB; images served via CDN.
