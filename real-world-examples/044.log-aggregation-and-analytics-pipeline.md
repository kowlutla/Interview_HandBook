# 044. Design a Log Aggregation & Analytics Pipeline (ELK Stack Scale)

## 1. Requirements
- Collect, parse, index, and query application logs from thousands of servers.
- Near real-time log search and visualization.

## 2. Architecture
- **Log Agents (Fluentbit / Logstash)**: Tail logs on servers and ship to message queue (Kafka).
- **Indexing & Storage (Elasticsearch)**: Ingests logs, builds inverted indexes, and provides Kibana dashboard querying.
