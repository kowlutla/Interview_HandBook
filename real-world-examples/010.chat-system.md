# 010. Design a Chat System (WhatsApp / Slack / Messenger)

## 1. Requirements
- 1-on-1 and group chat.
- Real-time messaging with low latency.
- Online/offline presence indicators.
- Message history persistence and delivery acknowledgments.

## 2. Architecture
- **Protocol**: WebSockets for persistent bi-directional client-server connection.
- **Chat Servers**: Stateless servers maintaining WebSocket connections.
- **Message Storage**: Cassandra/HBase for time-series message history.
- **Service Discovery**: Direct clients to correct chat server instances.
