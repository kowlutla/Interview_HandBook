# 006. Design a Unique ID Generator in Distributed Systems (Twitter Snowflake)

## 1. Requirements
- Generate unique 64-bit IDs across multiple distributed nodes.
- Sortable by time (chronologically ordered).
- High throughput (10,000+ IDs per second per node).

## 2. Snowflake ID Structure (64 bits)
- **Sign bit (1 bit)**: Always 0.
- **Timestamp (41 bits)**: Milliseconds since custom epoch. Supports ~69 years.
- **Datacenter ID (5 bits)**: Supports up to 32 datacenters.
- **Machine ID (5 bits)**: Supports up to 32 machines per datacenter.
- **Sequence number (12 bits)**: Incremented for every ID generated within that millisecond (4096 IDs/ms per machine).
