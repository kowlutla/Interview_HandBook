# 038. Design a Metrics Monitoring & Alerting System (Datadog / Prometheus)

## 1. Requirements
- Collect millions of time-series metrics per second.
- Fast dashboard querying and threshold alerting.

## 2. Architecture
- **Time-Series Database (TSDB)**: Optimized for time-ordered metrics storage and compression (Prometheus / InfluxDB).
- **Pull vs Push Model**: Prometheus pulls metrics; StatsD/Datadog agents push metrics.
