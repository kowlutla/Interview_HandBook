# 021. Design an Online Code Execution Engine (LeetCode / HackerRank)

## 1. Requirements
- Accept user source code, compile/interpret, run against test cases, and return results securely.
- Strict isolation and resource limits (CPU, memory, execution timeout).

## 2. Architecture
- **Sandbox**: Docker containers or firecracker microVMs with strict cgroups limits.
- **Worker Queue**: RabbitMQ dispatches execution jobs to worker nodes.
