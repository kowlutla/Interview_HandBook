# 045. Design a URL Preview Generator (Link Unfurling Service)

## 1. Requirements
- When a user pastes a URL in a chat/post, generate a rich preview card (title, description, thumbnail image).
- Prevent abuse/scraping loops and cache previews.

## 2. Architecture
- **Scraper Workers**: Fetch HTML metadata (Open Graph tags).
- **Image Resizer & Storage**: Download thumbnail, resize, and upload to S3/CDN.
- **Cache**: Store generated previews in Redis keyed by URL hash with TTL.
