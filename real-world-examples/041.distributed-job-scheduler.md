# 041. Design a Distributed Job Scheduler (Cron / Airflow)

## 1. Requirements
- Execute scheduled jobs reliably across distributed worker nodes.
- Prevent duplicate execution of the same job instance.

## 2. Architecture
- **Leader Election**: ZooKeeper/Etcd elects coordinator node.
- **Scheduler Ring / Timer Wheel**: Identifies jobs due for execution and pushes to worker queues.
