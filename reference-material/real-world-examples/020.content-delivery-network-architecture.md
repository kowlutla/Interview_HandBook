# 020. Design a Content Delivery Network (CDN) Architecture

## 1. Requirements
- Global distribution of static and dynamic content.
- Low latency routing via Anycast DNS.
- Cache invalidation and purging mechanisms.

## 2. Architecture
- Points of Presence (PoPs) globally with caching proxy servers (Squid/Varnish/Nginx).
- Origin shield to protect backend servers from cache stampedes.
