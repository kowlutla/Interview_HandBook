# 007. Design a Distributed Lock Manager (Redlock / ZooKeeper)

## 1. Requirements
- Ensure mutual exclusion across distributed nodes.
- Deadlock prevention / automatic expiration (TTL).
- High availability and fault tolerance.

## 2. Approaches
- **ZooKeeper / Etcd**: Consensus-based ephemeral sequential nodes.
- **Redis (Redlock)**: Multi-node Redis locking algorithm with quorum and drift time calculation.
