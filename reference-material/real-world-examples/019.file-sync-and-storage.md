# 019. Design File Sync & Storage (Google Drive / Dropbox)

## 1. Requirements
- File synchronization across multiple user devices.
- Chunking large files into smaller blocks for efficient incremental sync.
- Version history and conflict resolution.

## 2. Architecture
- **Block Splitter**: Splits files into 4MB chunks, deduplicates via cryptographic hashes (SHA-256).
- **Metadata Database**: Tracks file tree, block pointers, and user ownership.
- **Sync Engine**: Long-polling or WebSockets notify clients of changes.
