# 005. Design a Distributed Key-Value Store (Dynamo / Cassandra)

## 1. Problem Statement & Requirements
### Functional Requirements:
- `put(key, value)` and `get(key)` APIs.
- Highly available and partition tolerant (AP system under CAP theorem).
- Scalable to support massive write and read throughput.

## 2. Core Distributed Systems Principles
- **Partitioning**: Consistent hashing with virtual nodes.
- **Replication**: Data replicated across $N$ physical nodes.
- **Consistency**: Quorum-based consistency ($R + W > N$).
- **Handling Failures**: Sloppy quorums, hinted handoff, and anti-entropy via Merkle trees.

## 3. Storage Engine
- LSM-Trees (Log-Structured Merge-Trees) for high write throughput (MemTable + SSTables).
