# 011. Design a Scalable Notification System

## 1. Requirements
- Support multiple channels: Push notifications (APNS/FCM), SMS, Email.
- Asynchronous queuing with priority handling.
- Deduplication and user preference management.

## 2. Architecture
- **Workers & Queues**: RabbitMQ / Kafka queues per notification channel.
- **Third-Party Providers**: Twilio (SMS), SendGrid (Email), APNS/FCM (Push).
