# 043. Design a Feature Flag Management System (LaunchDarkly)

## 1. Requirements
- Dynamically enable/disable features in production without redeploying code.
- Target flags to specific user segments, percentages, or beta testers.

## 2. Architecture
- **Control Plane**: Dashboard where engineers toggle flags and define targeting rules.
- **Data Plane / SDK**: Client SDKs cache flag rules locally in memory, evaluating feature flags instantly with zero network latency.
