# 040. Design a Collaborative Document Editor (Google Docs / Notion)

## 1. Requirements
- Real-time collaborative text editing without conflicts.
- Offline editing with automatic sync upon reconnection.

## 2. Architecture
- **CRDTs (Conflict-free Replicated Data Types)** or **Operational Transformation (OT)** algorithms resolve concurrent edits deterministically without central locks.
- WebSockets for real-time patch broadcasting.
