# 025. Design Typeahead Suggestion (Search Autocomplete)

## 1. Requirements
- Return top 5 search suggestions as the user types prefix queries.
- Sub-50ms latency.

## 2. Architecture
- **Trie (Prefix Tree)** stored in memory (Redis / Custom Trie service).
- **Frequency Ranking**: Pre-compute top queries using MapReduce/Spark and update Trie periodically.
