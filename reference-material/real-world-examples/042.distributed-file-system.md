# 042. Design a Distributed File System (HDFS / Ceph)

## 1. Requirements
- Store and manage petabytes of files reliably across commodity servers.
- High throughput for large file reads/writes.

## 2. Architecture
- **NameNode / Metadata Server**: Manages file namespace, directory tree, and block locations.
- **DataNodes / Storage Nodes**: Store actual data blocks with replication (typically 3x).
