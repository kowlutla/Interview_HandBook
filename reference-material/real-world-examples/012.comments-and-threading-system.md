# 012. Design a Comments & Threading System (Reddit / HackerNews)

## 1. Requirements
- Nested replies (arbitrary depth).
- Upvoting/downvoting and sorting (hot, top, new).
- High read scalability.

## 2. Data Model
- Adjacency list (parent_id) vs. Closure table vs. Materialized path for tree structures. Relational or NoSQL with pagination.
