# 024. Design a Proximity Service (Yelp / Nearby Friends)

## 1. Requirements
- Find points of interest or friends within a given radius (e.g., 5km).
- Low latency queries on dynamic geospatial data.

## 2. Architecture
- **Geohash / H3 Grid Indexing**: Divide map into grid cells; store entities by cell ID in Redis or MySQL.
- **Geospatial Database**: Redis geospatial commands (`GEORADIUS`) or PostgreSQL PostGIS extensions.
