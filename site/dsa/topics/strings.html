START WITH THE RIGHT QUESTION

How should I approach a string problem?

Do not start by writing loops. First identify what the problem asks you to preserve: character frequency, relative order, a one-to-one relationship, or a pattern between neighbouring positions.

  1. Understand the contractInput size, allowed characters, case sensitivity and expected output.
  2. Find the relationshipAre we counting, matching, mapping, comparing or constructing?
  3. Choose what to rememberA frequency array, map, last-seen index, two pointers or a stack.
  4. State the invariantExplain what must remain true after every iteration.
  5. Test the boundary casesRepeated characters, collisions, empty input and the smallest valid input.
