START WITH THE SHAPE

How to derive a pattern

Study one row at a time. Separate leading spaces, visible symbols and inner gaps. Express each count using the row index and N, then translate those formulas into loops.

  1. Identify the rowsIs the height N, 2N−1, or a fixed number?
  2. Count each regionLeading spaces, left symbols, middle gap and right symbols.
  3. Find the row formulaDoes the count grow, shrink, stay fixed or mirror around the centre?
  4. Write loops by regionKeep separate visual regions in separate loops while learning.
  5. Dry-run the boundariesCheck the first, middle and last rows, especially N=1.

Important pattern-solving habit

Do not guess loop bounds from the picture. Write the number of spaces and symbols for row 1, row 2 and the last row. The formula usually becomes obvious once the sequence is visible.
