Alphabet hill pattern

Print a centred alphabet sequence that rises from A to a peak letter and then descends back to A.

1. Understand the problem

Given N, print N centred rows. Row i contains A,B,... up to the i-th letter, then returns through the preceding letters to A. Each row is a character palindrome.

✓ N = 4n = 4
      A
    A B A
  A B C B A
A B C D C B A

Leading indentation shrinks while the alphabet sequence grows symmetrically.

✓ N = 1n = 1
A

The hill consists of its single peak.

  • 1 ≤ N ≤ 26 for the uppercase English alphabet.
  • Row i has 2i−1 letters.
  • The source uses two spaces per leading indentation unit and prints a space after each letter.
What the output requires: The sequence rises until the centre column and then falls. The peak letter appears once; A appears at both ends unless N=1.

2. Build the intuition

A row can be built by walking up the alphabet to its centre, then walking back down. The source uses a character variable: increment it until column i, then decrement it for the remaining columns. The leading spaces centre the row.
💡
Key observation

For row i, there are N−i indentation units and 2i−1 letters. The character offset at column j is min(j−1, 2i−1−j).

3. Derive the loop structure

The code uses one character variable initialized just before A. It increments for the first i columns, then decrements for the remaining i−1 columns.
Row formula
For row i

Leading indentation units = N−i (two printed spaces per unit). Letter count = 2i−1. Character sequence = A..(A+i−1)..A.

  1. Iterate row i from 1 through N.
  2. Print two spaces for each of N−i indentation units.
  3. Initialize the current character to 'A'−1.
  4. For columns 1..2i−1, increment the character while col≤i; otherwise decrement it.
  5. Print the character followed by one space, then finish the row.

4. Java implementation from your DSA repository

This is `alphaHill` from the source. The character changes direction at the centre column; this is why the test is `col > row`.

public static void alphaHill(int n) {
    for (int row = 1; row <= n; row++) {
        // Two spaces per indentation unit centre the row.
        for (int space = 1; space <= n - row; space++) {
            System.out.print("  ");
        }
        char ch = 'A' - 1;
        for (int col = 1; col <= 2 * row - 1; col++) {
            // Rise to the peak, then descend toward A.
            if (col > row) {
                ch--;
            } else {
                ch++;
            }
            System.out.print(ch + " ");
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original source is AlphaHillPattern.java. The example and dry run follow the method's loop bounds and spacing.

5. Dry run: n = 4

For row 3, the indentation is one unit (two spaces). The character begins before A, rises for columns 1–3, then falls for columns 4–5.

The peak appears at the centre column of each row. The row width is always odd, so there is exactly one centre position.

6. Why does this work?

For the first i columns, the character is incremented from A−1 to the i-th letter. For the remaining i−1 columns, it is decremented, producing the reverse prefix without repeating the peak. The indentation decreases by one unit per row, centring the expanding sequence.

  • The increasing phase executes i times and the decreasing phase executes i−1 times.
  • The total letter count is 2i−1, so the centre is a single position.
  • N≤26 keeps every generated character within A–Z.

7. Complexity analysis

TIMEO(n²)

Row i emits 2i−1 letters and 2(N−i) leading spaces; the total output is Θ(N²).

AUXILIARY SPACEO(1)

Only loop counters and a constant number of scalar variables are used. The printed output is excluded from auxiliary space.

Here n is the input row count. Count the actual emitted positions, including spaces, when deriving the time bound.

8. Common mistakes and edge cases

  • Decrementing at `col >= row` skips the peak letter.
  • Using only one leading space per indentation unit changes the horizontal alignment because letters are separated by spaces.
  • Allowing N>26 produces characters beyond Z.

Remember: For a palindromic alphabet hill, change direction only after printing the centre character.
