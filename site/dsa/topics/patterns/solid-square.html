Solid square pattern

Print an N × N square in which every position contains a star.

1. Understand the problem

Given a positive integer N, print N rows, each containing exactly N stars. Keep the same number of columns in every row.

✓ N = 3n = 3
* * *
* * *
* * *

Three rows, each with three stars.

✓ N = 1n = 1
*

The smallest valid square contains one cell.

  • N is a positive integer.
  • There are exactly N rows and N columns.
  • The original source prints a space after each star; the displayed output keeps separators between adjacent stars.
What the output requires: Unlike a triangle, the inner-loop bound does not depend on the current row. Every row has the same width.

2. Build the intuition

Think of the output as an N × N grid. The outer loop chooses a row. For every row, the inner loop visits all N columns. Nothing about the row changes the number of columns to print.
💡
Key observation

The outer loop runs N times and the inner loop runs N times for every outer iteration. The total number of stars is N².

3. Derive the loop structure

No spaces or boundary checks are needed. The pattern is a direct traversal of a rectangular grid.
Row formula
For row i

Rows: 1..N. Columns on every row: 1..N. The symbol count per row is always N.

  1. Start the row counter at 1 and continue through N.
  2. For each row, print one star for each column from 1 through N.
  3. Print a newline only after all N columns have been printed.

4. Java implementation from your DSA repository

The method below is the same nested-loop structure as `printPattern` in the source file, with comments that explain the row and column roles.

public static void printPattern(int n) {
    for (int row = 1; row <= n; row++) {
        // Every row contains exactly n columns.
        for (int col = 1; col <= n; col++) {
            System.out.print("* ");
        }
        // Finish the current row.
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original Java source is available at RectanglePattern.java. The example above and the dry run below follow this method's loop bounds and spacing.

5. Dry run: n = 3

The outer loop selects rows 1, 2 and 3. The inner loop always runs three times, so each row prints the same three cells.

The output contains 3 × 3 = 9 stars. The row width never changes.

6. Why does this work?

The outer loop visits each required row exactly once. For a fixed row, the inner loop visits every column from 1 to N and emits one star per column. Thus each row has exactly N stars and there are exactly N rows.

  • The inner-loop bound is independent of row, so all rows have equal width.
  • The outer loop terminates after row N, so no extra row is printed.

7. Complexity analysis

TIMEO(n²)

There are N outer iterations and N star emissions per row, for exactly N² star emissions.

AUXILIARY SPACEO(1)

Only loop counters and a constant number of scalar variables are used. The printed output is not counted as auxiliary storage.

Here n is the input row count. Count the actual emitted positions (including spaces) when deriving the bound; the running time is proportional to the output size.

8. Common mistakes and edge cases

  • Using `col <= row` accidentally changes the square into a growing triangle.
  • Printing the newline inside the inner loop creates N one-star lines.
  • If exact output is checked, match the required separator and trailing-space convention.
