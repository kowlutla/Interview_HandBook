Reverse letter triangle

Print rows that begin with A and contain progressively shorter prefixes of the alphabet.

1. Understand the problem

Given N, print N rows. The first row contains the first N uppercase letters beginning at A. Each following row removes the final letter, until the last row contains only A.

✓ N = 4n = 4
A B C D
A B C
A B
A

The first character stays A; the row length shrinks.

✓ N = 1n = 1
A

One letter in one row.

  • N is positive and at most 26 for uppercase English letters.
  • Every row starts at A.
  • Row i contains N−i+1 letters.
What the output requires: This pattern is different from a descending alphabet triangle: the letters themselves always increase from A; only the row length decreases.

2. Build the intuition

The starting character never changes. The inner loop walks forward through the alphabet, but its upper bound gets smaller on every new row.
💡
Key observation

For row i, print N−i+1 characters. The character at zero-based offset j is 'A'+j.

3. Derive the loop structure

The source uses a `char` loop from A up to, but not including, A+N−i+1. This directly expresses the decreasing prefix length.
Row formula
For row i

Length = N−i+1. Characters = A,B,...,A+(N−i).

  1. Iterate row i from 1 through N.
  2. Compute the exclusive end character as 'A' + N−i+1.
  3. Start a character loop at A and print until the exclusive end.
  4. Print newline.

4. Java implementation from your DSA repository

This is `nLetterTriangle` from `ReverseLetterTrianglePattern.java`.

public static void nLetterTriangle(int n) {
    for (int row = 1; row <= n; row++) {
        // Each row starts from A; only its length changes.
        char endExclusive = (char) ('A' + n - row + 1);
        for (char ch = 'A'; ch < endExclusive; ch++) {
            System.out.print(ch + " ");
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original source is ReverseLetterTrianglePattern.java. The example and dry run follow the method's loop bounds and spacing.

5. Dry run: n = 4

The exclusive end character moves one position toward A after every row.

RowLeading spacesSymbols / valuesInner gapResult
1—A..D (4)—A B C D
2—A..C (3)—A B C
3—A..B (2)—A B
4—A (1)—A

The row lengths are 4,3,2,1. The inner character loop always begins at A, so no character sequence is carried over from the previous row.

6. Why does this work?

For row i, the loop includes exactly the characters from A through A+N−i, which is N−i+1 characters. Since i increases from one to N, this length decreases from N to one while every row starts at A.

  • The start value A is reset on each row.
  • The exclusive upper bound prevents printing one extra letter.

7. Complexity analysis

TIMEO(n²)

The total letters printed are N+(N−1)+...+1 = Θ(N²).

AUXILIARY SPACEO(1)

Only loop counters and a constant number of scalar variables are used. The printed output is excluded from auxiliary space.

Here n is the input row count. Count the actual emitted positions, including spaces, when deriving the time bound.

8. Common mistakes and edge cases

  • Decrementing the character each time creates a different pattern.
  • Starting the character loop at the previous row's end means later rows no longer begin at A.
  • N above 26 moves beyond uppercase A–Z and should be rejected under this contract.
