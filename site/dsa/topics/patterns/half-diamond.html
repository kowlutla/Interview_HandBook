Half-diamond star pattern

Print a left-aligned star pattern that grows from one star to N and then shrinks back to one.

1. Understand the problem

Given N, print a left-aligned half-diamond. The first row has one star; the count increases by one until row N, then decreases by one on each remaining row.

✓ N = 4n = 4
*\n**\n***\n****\n***\n**\n*

The widest row is printed once.

✓ N = 1n = 1
*

The growth and shrink phases collapse into one row.

  • N is positive.
  • The outer loop runs from 1 through 2N−1.
  • The star count on row i is i when i≤N, otherwise 2N−i.
What the output requires: The pattern is left-aligned; no leading spaces are needed.

2. Build the intuition

The number of stars forms a mountain sequence: 1,2,...,N,...,2,1. The peak N must not be repeated, so the loop stops before 2N.
💡
Key observation

The current row itself gives the star count in the upper half. After the peak, reflect the row index around N using 2N−i.

3. Derive the loop structure

The source uses one outer loop for both halves. It starts with `end=i`, then replaces it with `2N−i` after the centre.
Row formula
For row i

Rows: 1≤i<2N. Stars = min(i, 2N−i).

  1. Iterate i from 1 while i<2N.
  2. Set end=i for the growing half.
  3. When i>N, set end=2N−i for the shrinking half.
  4. Print end stars and a newline.

4. Java implementation from your DSA repository

This is `nStarTriangle` from the repository. The variable `end` stores the number of stars for the current row.

public static void nStarTriangle(int n) {
    for (int row = 1; row < 2 * n; row++) {
        // Grow to n stars, then mirror the count back down.
        int stars = row;
        if (row > n) {
            stars = 2 * n - row;
        }
        for (int col = 1; col <= stars; col++) {
            System.out.print("*");
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original Java source is available at HalfDiamondStarPattern.java. The example above and the dry run below follow this method's loop bounds and spacing.

6. Why does this work?

For rows 1 through N, `stars=row`, which increases from 1 to N. For rows N+1 through 2N−1, `stars=2N−row`, which decreases from N−1 to 1. The loop visits exactly those row indices, so the output grows and shrinks symmetrically.

  • The condition `row < 2*n` excludes row 2N, preventing a zero-star row.
  • The condition `row > n` leaves the peak row in the growing half only.

7. Complexity analysis

TIMEO(n²)

The number of printed stars is N+(N−1)+...+1 + (N−1)+...+1 = N².

AUXILIARY SPACEO(1)

Only loop counters and a constant number of scalar variables are used. The printed output is not counted as auxiliary storage.

Here n is the input row count. Count the actual emitted positions (including spaces) when deriving the bound; the running time is proportional to the output size.

8. Common mistakes and edge cases

  • Using `row <= 2*n` adds an unwanted final row with zero stars.
  • Using `2*n-row+1` repeats the peak and shifts the lower half.
  • A separate upper and lower loop is possible, but the reflected formula is concise.

Remember: For a grow-then-shrink pattern, reflect the row index around the peak instead of duplicating the peak.
