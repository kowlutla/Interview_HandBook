Repeated row-number triangle

Print row i with the integer i repeated exactly i times.

1. Understand the problem

Given N, print N rows. Row i contains i copies of the integer i.

✓ N = 4n = 4
1
2 2
3 3 3
4 4 4 4

Both the row width and the repeated value increase together.

✓ N = 1n = 1
1

One copy of the row number.

  • N is positive.
  • Row i contains exactly i values.
  • Every value on row i equals i.
What the output requires: The printed value is the row number, not the column number. The column loop only controls repetition.

2. Build the intuition

Compare this with the ascending number triangle. There, the column index is printed. Here, the row index is printed repeatedly. The same nested-loop shape produces a different pattern simply by changing the value expression.
💡
Key observation

Print `row` inside the inner loop. The inner-loop bound is also `row`.

3. Derive the loop structure

For each row i, repeat the print operation i times. The row variable stays unchanged during the inner loop.
Row formula
For row i

Number of values = i; value at every column = i.

  1. Iterate row from 1 through N.
  2. Repeat the inner loop from 1 through row.
  3. Print the current row number on each inner iteration.
  4. Move to a new line.

4. Java implementation from your DSA repository

This is the `nTriangle` method from `RightAngledNumberPyramid2.java`.

public static void nTriangle(int n) {
    for (int row = 1; row <= n; row++) {
        // Repeat the row number once for every column in this row.
        for (int col = 1; col <= row; col++) {
            System.out.print(row + " ");
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original Java source is available at RightAngledNumberPyramid2.java. The example above and the dry run below follow this method's loop bounds and spacing.

5. Dry run: n = 4

For each row, the outer-loop value stays constant while the inner loop repeats it a number of times equal to that value.

RowLeading spacesSymbols / valuesInner gapResult
1—1 repeated once—1
2—2 repeated twice—2 2
3—3 repeated 3 times—3 3 3
4—4 repeated 4 times—4 4 4 4

There are 10 values in total. Row 4 prints four copies of 4, not the sequence 1,2,3,4.

6. Why does this work?

For each row i, the outer loop fixes the value i. The inner loop runs i times and prints that unchanged value on every iteration. Therefore row i contains exactly i copies of i.

  • The row value is constant during the inner loop.
  • The inner loop count equals the row number, giving the required row length.

7. Complexity analysis

TIMEO(n²)

The method prints 1+2+...+N values.

AUXILIARY SPACEO(1)

Only loop counters and a constant number of scalar variables are used. The printed output is not counted as auxiliary storage.

Here n is the input row count. Count the actual emitted positions (including spaces) when deriving the bound; the running time is proportional to the output size.

8. Common mistakes and edge cases

  • Printing col creates the ascending number triangle instead.
  • Incrementing row inside the inner loop changes the value before the row is complete.
  • A global counter would create Floyd's triangle.

Remember: The choice between printing row or column is what distinguishes two visually similar number triangles.
