Hollow square pattern

Print an N × N square with stars on its boundary and spaces in its interior.

Problem 04EasyJava solutionNested-loop reasoning

Each cell is a star if it lies on any of the four borders; otherwise it is blank.

1. Understand the problem

Given N, print an N × N square. Print a star in the first or last row, or in the first or last column. Print a space in every interior cell. Although the source class is named `HollowRectanglePattern`, its method uses N rows and N columns, so the shape is a square.

✓ N = 5n = 5

Only the four edges contain stars.

✓ N = 2n = 2
**
**

A 2 × 2 grid has no interior cells; every cell is on the border.

  • N is positive.
  • The output has N rows and N columns.
  • The interior is present only when N ≥ 3.
What the output requires: For a cell at (row, col), the border condition is `row == 1 || row == N || col == 1 || col == N`.

2. Build the intuition

Imagine visiting every cell in an N × N grid. A cell belongs to the border if it is on the top edge, bottom edge, left edge or right edge. The four checks are joined with OR because satisfying any one of them is enough.
💡
Key observation

The condition is an OR across the four borders. Interior cells are exactly those for which all four border checks are false.

3. Derive the loop structure

Use the same two loops as a solid square, but choose the printed character using the border predicate.
Row formula
For cell (i, j)

Print `*` when i=1, i=N, j=1 or j=N. Otherwise print one blank. Newline after each row.

  1. Visit each row from 1 through N.
  2. For each row, visit each column from 1 through N.
  3. Evaluate the four-border condition.
  4. Print `*` for a border cell; otherwise print a space.
  5. Finish the row with a newline.

4. Java implementation from your DSA repository

This is `getStarPattern` from the repository. The method name is retained in the source link; the explanation calls the shape a square because both dimensions use N.

public static void getStarPattern(int n) {
    for (int row = 1; row <= n; row++) {
        for (int col = 1; col <= n; col++) {
            // A cell is on the boundary if it touches any edge.
            if (row == 1 || col == 1 || row == n || col == n) {
                System.out.print("*");
            } else {
                System.out.print(" ");
            }
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original Java source is available at HollowRectanglePattern.java. The example above and the dry run below follow this method's loop bounds and spacing.

6. Why does this work?

The nested loops visit every coordinate in the square exactly once. The condition is true precisely for coordinates on one of the four edges. All other coordinates are interior and receive a blank. Thus the algorithm prints the hollow square boundary and leaves its interior empty.

  • The OR condition covers every border and no interior cell.
  • The inner loop still visits all N columns, preserving the square's width.

7. Complexity analysis

TIMEO(n²)

The algorithm examines all N² cells once, regardless of whether a cell prints a star or a blank.

AUXILIARY SPACEO(1)

Only loop counters and a constant number of scalar variables are used. The printed output is not counted as auxiliary storage.

Here n is the input row count. Count the actual emitted positions (including spaces) when deriving the bound; the running time is proportional to the output size.

8. Common mistakes and edge cases

  • Using AND between the border checks would require a cell to be on all four edges at once.
  • Omitting interior spaces collapses the right and left edges together.
  • The class name says rectangle, but the method prints an N × N square.
  • N=1 and N=2 have no visible hollow interior.
