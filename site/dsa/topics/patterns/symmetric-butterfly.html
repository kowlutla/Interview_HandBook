Symmetric butterfly pattern

Print two mirrored star wings that grow toward the centre and shrink away from it.

1. Understand the problem

Given N, print 2N−1 rows. Each row contains a left group of stars, a central gap and an equal right group of stars. The wings grow from one star to N stars, then shrink symmetrically.

✓ N = 3n = 3
*         * 
* *     * * 
* * * * * * 
* *     * * 
*         *

The centre row has no central gap and N stars in each wing.

✓ N = 1n = 1
* *

One row with one star in each wing.

  • N is positive.
  • There are 2N−1 rows.
  • Each star is printed as `* ` and each gap unit as two spaces, matching the source formatting.
What the output requires: The left and right wing widths are identical. The number of stars per wing grows to N and then decreases.

2. Build the intuition

The upper half grows outward from the left and right edges while the gap closes. After the centre row, the same widths appear in reverse order. The source handles both halves in one loop by reflecting the row index around N.
💡
Key observation

For row i, wingStars = min(i,2N−i). The number of central gap units is 2|N−i|.

3. Derive the loop structure

Use 2N−1 rows. Compute the wing width once. Compute the gap count from the distance to the centre row, then print left stars, gap and right stars.
Row formula
For row i

Wing stars = min(i,2N−i). Gap iterations = 2|N−i|. Each gap iteration prints two spaces.

  1. Iterate i from 1 through 2N−1.
  2. Set starEnd=i; if i>N, set starEnd=2N−i.
  3. Set spaceEnd=2(N−i); if negative, make it positive.
  4. Print starEnd groups of `* ` on the left.
  5. Print spaceEnd groups of two spaces, then the same star groups on the right.

4. Java implementation from your DSA repository

This is `symmetry` from the repository. The source converts a negative gap count into a positive count in the lower half.

public static void symmetry(int n) {
    for (int row = 1; row <= 2 * n - 1; row++) {
        int starEnd = row;
        if (row > n) {
            starEnd = 2 * n - row;
        }
        for (int col = 1; col <= starEnd; col++) {
            System.out.print("* ");
        }

        int spaceEnd = 2 * (n - row);
        if (row > n) {
            spaceEnd = -spaceEnd;
        }
        for (int gap = 1; gap <= spaceEnd; gap++) {
            System.out.print("  ");
        }

        for (int col = 1; col <= starEnd; col++) {
            System.out.print("* ");
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original source is SymmetricButterflyPattern.java. The example and dry run follow the method's loop bounds and spacing.

5. Dry run: n = 3

The centre is row 3. Before it, the star count rises and the gap shrinks; after it, the star count falls and the gap expands.

6. Why does this work?

The expression for the wing width reflects row indices after the centre: it increases to N and then decreases. The absolute gap count is zero exactly at the centre and increases equally on both sides. Printing the same wing width on the left and right makes every row horizontally symmetric.

  • The row range 1..2N−1 contains one centre row.
  • The reflected wing formula is symmetric: wing(i)=wing(2N−i).
  • The gap depends only on distance from the centre row.

8. Common mistakes and edge cases

  • Using 2N rows duplicates the centre row.
  • Forgetting to make the lower-half gap positive results in no gap after the centre.
  • Printing a different star count on the right breaks the butterfly symmetry.
