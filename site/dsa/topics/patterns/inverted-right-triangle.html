Inverted right-angle star triangle

Print N rows, starting with N stars and removing one star from each following row.

1. Understand the problem

Given N, print a left-aligned inverted right-angle triangle. The first row contains N stars. Each next row contains one fewer star, ending with one star.

✓ N = 4n = 4
* * * *
* * *
* *
*

The row width decreases from four to one.

✓ N = 1n = 1
*

Only the widest and narrowest row are the same row.

  • N is positive.
  • There are exactly N rows.
  • The number of stars on row i is N−i+1.
What the output requires: Keep the left edge fixed. Only the number of stars changes from row to row.

2. Build the intuition

This is the reverse of the growing triangle. Instead of using the row number as the star count, use the remaining width. Start at N and decrement after each line.
💡
Key observation

The outer loop can count down from N to 1; the inner loop prints as many stars as the current outer-loop value.

3. Derive the loop structure

The original method uses a descending outer loop. For each value i, it prints i stars and then starts the next line.
Row formula
For remaining width i

Rows use i = N, N−1, ..., 1. Stars on the current row = i; leading spaces = 0.

  1. Initialize the row width to N.
  2. While the row width is at least 1, print that many stars.
  3. Print a newline and decrement the row width by one.

4. Java implementation from your DSA repository

This is the `seeding` method from the source, renamed only in the explanation; its loop bounds and `* ` spacing are preserved.

public static void seeding(int n) {
    // The row width decreases from n down to 1.
    for (int rowWidth = n; rowWidth >= 1; rowWidth--) {
        for (int col = 1; col <= rowWidth; col++) {
            System.out.print("* ");
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original Java source is available at InvertedRightPyramid.java. The example above and the dry run below follow this method's loop bounds and spacing.

5. Dry run: n = 4

The outer-loop value is also the number of stars printed in that row.

RowLeading spacesSymbols / valuesInner gapResult
404 stars—* * * *
303 stars—* * *

The row widths are 4, 3, 2, 1. The total number of stars is again N(N+1)/2, but their order is reversed.

6. Why does this work?

The outer loop visits each integer from N down to 1 exactly once. For each value i, the inner loop emits exactly i stars. Therefore the rows have the required decreasing widths and the final row contains one star.

  • The descending outer-loop variable cannot skip a width because it decreases by exactly one.
  • The inner loop terminates at the current width, so each line has the required number of stars.

7. Complexity analysis

TIMEO(n²)

The number of emitted stars is N+(N−1)+...+1 = N(N+1)/2.

AUXILIARY SPACEO(1)

Only loop counters and a constant number of scalar variables are used. The printed output is not counted as auxiliary storage.

Here n is the input row count. Count the actual emitted positions (including spaces) when deriving the bound; the running time is proportional to the output size.

8. Common mistakes and edge cases

  • Counting the outer loop upward without changing the inner-loop formula prints the opposite triangle.
  • Using `rowWidth > 1` omits the final one-star row.
  • Do not print the newline inside the inner loop.
