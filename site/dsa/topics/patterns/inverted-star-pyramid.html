Inverted centered star pyramid

Print an inverted centred pyramid that starts with 2N−1 stars and shrinks to one.

Problem 06EasyJava solutionNested-loop reasoning

EASY

1. Understand the problem

Given N, print N rows. The first row is the widest, with 2N−1 stars. Each following row is indented by one more space and contains two fewer stars, ending with one star.

✓ N = 4n = 4
*******
 *****
  ***
   *

The star count decreases 7, 5, 3, 1.

✓ N = 1n = 1
*

The only row contains one star.

  • N is positive.
  • Row i has i−1 leading spaces.
  • The star count on row i is 2N−2i+1.
What the output requires: The right and left edges move inward symmetrically. The source prints matching trailing spaces after the stars.

2. Build the intuition

This is the reverse of the normal pyramid. Instead of removing one leading space and adding two stars, each row adds one leading space and removes two stars.
💡
Key observation

The remaining odd width is 2(N−i)+1. The indentation is i−1.

3. Derive the loop structure

Use one outer loop from row 1 to N. Print row−1 spaces, then the remaining odd number of stars, then matching trailing spaces as in the source.
Row formula
For row i

Leading spaces = i−1; stars = 2N−2i+1; trailing spaces = i−1.

  1. Iterate row i from 1 through N.
  2. Print i−1 leading spaces.
  3. Print 2N−2i+1 stars.
  4. Print i−1 trailing spaces.
  5. Finish the row.

4. Java implementation from your DSA repository

This method is `nStarTriangle` from the source. Its odd-width formula is written explicitly to show why the star count reaches one.

public static void nStarTriangle(int n) {
    for (int row = 1; row <= n; row++) {
        // Indentation increases as the pyramid narrows.
        for (int space = 1; space < row; space++) {
            System.out.print(" ");
        }
        int stars = 2 * n - (2 * row - 1);
        for (int col = 1; col <= stars; col++) {
            System.out.print("*");
        }
        // Keep the source's right-side padding symmetric.
        for (int space = 1; space < row; space++) {
            System.out.print(" ");
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original Java source is available at InvertedStarPyramid.java. The example above and the dry run below follow this method's loop bounds and spacing.

6. Why does this work?

The indentation i−1 shifts each successive row one position right. The star count 2N−2i+1 is odd and decreases by two. These paired changes preserve the same centre column from the first row to the last.

  • At i=1, the star count is 2N−1 and indentation is zero.
  • At i=N, the star count is one and indentation is N−1.
  • The formula never produces zero or a negative star count for 1≤i≤N.

7. Complexity analysis

TIMEO(n²)

The star and padding characters emitted over N rows total Θ(N²).

AUXILIARY SPACEO(1)

Only loop counters and a constant number of scalar variables are used. The printed output is not counted as auxiliary storage.

Here n is the input row count. Count the actual emitted positions (including spaces) when deriving the bound; the running time is proportional to the output size.

8. Common mistakes and edge cases

  • Using 2N−2i instead of 2N−2i+1 removes the final star.
  • Indentation begins at zero, so use row−1 spaces.
  • Do not decrement the star count by one; a centred odd-width pyramid shrinks by two.
