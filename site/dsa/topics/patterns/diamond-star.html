1. Understand the problem

Given N, print a solid diamond using an upper growing pyramid and a lower shrinking pyramid. The source method runs both halves from 1 through N, so it prints the widest row twice and produces 2N rows. This is an implementation detail worth noticing rather than silently hiding.

✓ Source behavior · N = 3n = 3

The middle row is duplicated because both loops include i=N.

✓ Canonical single-centre variantn = 3
  *\n ***\n*****\n ***\n  *

A conventional diamond prints the widest row once; its lower half starts at N−1.

  • N is positive.
  • The upper half has N rows.
  • The repository implementation's lower half also has N rows, so its total is 2N.
  • The conventional single-centre variant has 2N−1 rows.
What the output requires: For the repository's exact loop bounds, preserve the duplicate widest row. If the goal is a conventional diamond, start the lower loop at N−1 and document that change.

2. Build the intuition

A diamond is not a new primitive shape: it is an expanding pyramid followed by an inverted pyramid. The upper half uses N−i spaces and 2i−1 stars. The lower half uses i−1 spaces and 2N−2i+1 stars.
💡
Key observation

The two halves meet at their widest row. Whether that row is printed once or twice depends on the lower loop's starting index.

3. Derive the loop structure

The source uses two separate loops. The first loop prints the normal pyramid. The second starts again at i=1, which repeats the base. The code below preserves the repository output; a one-line lower-loop change is shown after it.
Row formula
Upper and lower row formulas

Upper row i: spaces N−i, stars 2i−1. Lower row i: spaces i−1, stars 2N−2i+1. Source lower i starts at 1; canonical lower i starts at 2.

  1. Print the upper pyramid for i=1..N.
  2. Print N−i spaces and 2i−1 stars on each upper row.
  3. Print the lower half for i=1..N to match the repository output.
  4. For a conventional non-duplicated diamond, change the lower loop to start at i=N−1 and count down to 1.

4. Java implementation from your DSA repository

This is the source method `nStarDiamond`, simplified only by removing its interactive test-case wrapper. The duplicate middle row is retained to match the source output.

public static void nStarDiamond(int n) {
    // Upper half: a normal centred pyramid.
    for (int row = 1; row <= n; row++) {
        for (int space = 1; space <= n - row; space++) System.out.print(" ");
        for (int star = 1; star <= 2 * row - 1; star++) System.out.print("*");
        for (int space = 1; space <= n - row; space++) System.out.print(" ");
        System.out.println();
    }

    // Lower half: source starts at row 1, so the widest row is repeated.
    for (int row = 1; row <= n; row++) {
        for (int space = 1; space < row; space++) System.out.print(" ");
        int stars = 2 * n - (2 * row - 1);
        for (int star = 1; star <= stars; star++) System.out.print("*");
        for (int space = 1; space < row; space++) System.out.print(" ");
        System.out.println();
    }
}

6. Why does this work?

The upper loop produces the required increasing odd widths and indentation. The lower loop produces the exact reverse sequence. Together they form a vertically symmetric diamond-like shape. The source's lower loop starts at 1, so it deliberately or accidentally duplicates the widest row; the trace and stated row count match that code.

  • Upper star widths are 1,3,...,2N−1.
  • Lower star widths are 2N−1,...,3,1.
  • The two centre rows are identical because both halves include the maximum width.

7. Complexity analysis

TIMEO(n²)

There are Θ(N) rows and each row prints O(N) spaces and stars. The output itself is Θ(N²).

AUXILIARY SPACEO(1)

Only loop counters and a constant number of scalar variables are used. The printed output is not counted as auxiliary storage.

8. Common mistakes and edge cases

  • Assuming the source prints 2N−1 rows: it prints 2N because both halves include N.
  • Changing the lower loop without updating the example creates a code/output mismatch.
  • For the conventional version, start the lower half at N−1, not N.
