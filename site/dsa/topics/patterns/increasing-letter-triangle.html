Increasing letter triangle

Print A through the row's final letter, increasing the prefix length on each row.

1. Understand the problem

Given N, print N rows. Row i contains the uppercase letters A through the i-th letter, in increasing order.

✓ N = 4n = 4
A
A B
A B C
A B C D

Every row is a longer prefix of the alphabet.

✓ N = 1n = 1
A

One letter.

  • 1 ≤ N ≤ 26 for uppercase English letters.
  • Each row starts at A.
  • Row i contains i letters.
What the output requires: The character depends on the column, not the row. The row index controls the final column.

2. Build the intuition

At column one we print A, at column two B, at column three C, and so on. Each new row simply allows one more column to appear.
💡
Key observation

Map column j to (char)('A'+j−1), and stop the inner loop at the current row number.

3. Derive the loop structure

The source uses a `char` loop from A to A+i−1. The alternative integer-column expression is equivalent.
Row formula
For row i and column j

Columns = 1..i. Character at column j = 'A' + j−1.

  1. Iterate row i from 1 through N.
  2. Start a character variable at A.
  3. Print letters while the character is less than A+i.
  4. Print newline after the row.

4. Java implementation from your DSA repository

This is `nLetterTriangle` from the source. The loop uses the same exclusive upper bound as the repository implementation.

public static void nLetterTriangle(int n) {
    for (int row = 1; row <= n; row++) {
        // Every row starts at A and extends one character farther.
        for (char ch = 'A'; ch < 'A' + row; ch++) {
            System.out.print(ch + " ");
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original source is IncreasingLetterTrianglePattern.java. The example and dry run follow the method's loop bounds and spacing.

5. Dry run: n = 4

The inner-loop upper bound moves from B to C, D and E (exclusive), so one extra letter appears on each row.

RowLeading spacesSymbols / valuesInner gapResult
1—A (1)—A
2—A,B (2)—A B
3—A,B,C (3)—A B C
4—A,B,C,D (4)—A B C D

The total number of letters printed is 1+2+3+4 = 10.

6. Why does this work?

For row i, the character loop starts at A and includes every character strictly before A+i. That is exactly i consecutive letters. The outer loop visits all row numbers from one through N, giving the required growing prefixes.

  • The character variable resets to A on every row.
  • The exclusive upper bound A+row includes exactly row letters.

7. Complexity analysis

TIMEO(n²)

The total number of emitted letters is the triangular sum N(N+1)/2.

AUXILIARY SPACEO(1)

Only loop counters and a constant number of scalar variables are used. The printed output is excluded from auxiliary space.

Here n is the input row count. Count the actual emitted positions, including spaces, when deriving the time bound.

8. Common mistakes and edge cases

  • Using `ch <= 'A'+row` prints one extra letter.
  • Carrying the character variable across rows prevents each row from restarting at A.
  • The input must be capped at 26 for the stated A–Z contract.
