Concentric number square

Fill a (2N−1) × (2N−1) square with concentric layers, decreasing from N at the border to one at the centre.

1. Understand the problem

Given N, print a square of side length 2N−1. The outermost border contains N, the next inner layer contains N−1, and so on until the centre cell contains 1.

Each inward layer decreases the value by one.

✓ N = 1n = 1
1

The square has one cell, which is also its centre.

  • N is positive.
  • The side length is 2N−1.
  • The source uses 1-based row and column indices.
What the output requires: The value depends on the nearest edge, not on the row or column alone. Cells on the same concentric layer share the same value.

2. Build the intuition

For each cell, calculate how far it is from the top, bottom, left and right borders. The smallest of those four distances tells us which layer the cell belongs to. Subtract that layer number from N.
💡
Key observation

Let d=min(row−1, side−row, col−1, side−col). The cell value is N−d.

3. Derive the loop structure

Traverse the complete square. The four distance calculations are constant time, so there is no need to build the layers one at a time or store a separate matrix.
Row formula
For cell (i,j), with side=2N−1

top=i−1; bottom=side−i; left=j−1; right=side−j. Value = N−min(top,bottom,left,right).

  1. Compute side = 2N−1.
  2. Loop row and col from 1 through side.
  3. Calculate distance to each of the four borders.
  4. Take the minimum distance.
  5. Print N minus that minimum, then finish the row.

4. Java implementation from your DSA repository

This is `getNumberPattern` from the source. The code calculates the nearest-border distance for every cell.

public static void getNumberPattern(int n) {
    int side = 2 * n - 1;
    for (int row = 1; row < 2 * n; row++) {
        for (int col = 1; col < 2 * n; col++) {
            // Distance from this cell to each of the four borders.
            int top = row - 1;
            int bottom = side - row;
            int left = col - 1;
            int right = side - col;

            int layer = Math.min(Math.min(top, bottom),
                                 Math.min(left, right));
            int value = n - layer;
            System.out.print(value + " ");
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original source is TheNumberPattern.java. The example and dry run follow the method's loop bounds and spacing.

6. Why does this work?

Every cell is assigned the value N minus its minimum distance to any border. All cells on the same concentric layer have the same minimum distance and therefore the same value. The outer border has distance zero and value N; the centre has distance N−1 and value one. The nested loops visit every cell in the required (2N−1) square exactly once.

  • The minimum of the four distances uniquely identifies the cell's nearest layer.
  • The maximum possible minimum distance is N−1, at the centre.
  • The square side is 2N−1, so the centre is a single cell.

7. Complexity analysis

TIMEO(n²)

The algorithm visits (2N−1)² cells and performs a constant number of arithmetic and min operations per cell.

AUXILIARY SPACEO(1)

Only loop counters and a constant number of scalar variables are used. The printed output is excluded from auxiliary space.

Here n is the input row count. Count the actual emitted positions, including spaces, when deriving the time bound.

8. Common mistakes and edge cases

  • Using side=2N creates an even-sized grid with no single centre cell.
  • Using only top and left distances breaks the concentric symmetry.
  • The bottom and right distances must be measured from side, not from 2N.
  • For very large N, guard against overflow in 2*n−1.
