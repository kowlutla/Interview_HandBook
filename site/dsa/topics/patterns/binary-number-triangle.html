Binary number triangle

1. Understand the problem

Given N, print N rows of binary digits. Row i contains i digits. The first digit is 1 on odd-numbered rows and 0 on even-numbered rows; digits alternate within the row.

✓ N = 4n = 4
1
0 1
1 0 1
0 1 0 1

Each row begins with the opposite bit from the previous row.

✓ N = 1n = 1
1

The first row begins with one.

  • N is positive.
  • Only 0 and 1 are printed.
  • The source uses 1-based row and column indices.
What the output requires: The bit is determined by the parity of row+column+1. Incrementing either index flips the bit.

2. Build the intuition

Look at the first digit: it alternates 1,0,1,0 as the row increases. Within a row, every next column flips the bit again. Both behaviors can be expressed with one parity formula.
💡
Key observation

For 1-based row i and column j, `(i+j+1)%2` gives the required bit. The modulo result is always 0 or 1.

3. Derive the loop structure

Use the usual triangular nested loops. Instead of storing a current bit, compute it directly from the row and column indices.
Row formula
For row i and column j

Bit = (i+j+1) mod 2, with 1≤j≤i.

  1. Iterate row i from 1 through N.
  2. For each row, iterate col j from 1 through i.
  3. Compute `(i + j + 1) % 2`.
  4. Print the bit and a separator.
  5. Finish the row.

4. Java implementation from your DSA repository

This is `nBinaryTriangle` from the source, with the parity expression annotated.

public static void nBinaryTriangle(int n) {
    for (int row = 1; row <= n; row++) {
        for (int col = 1; col <= row; col++) {
            // Moving one row or one column flips the parity.
            int bit = (row + col + 1) % 2;
            System.out.print(bit + " ");
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original source is BinaryNumberTrianglePattern.java. The example and dry run follow the method's loop bounds and spacing.

6. Why does this work?

For fixed row i, increasing col by one changes the parity of i+col+1, so adjacent bits differ. Increasing row by one also changes parity, so the first bit alternates between rows. The inner loop prints exactly i bits.

  • Modulo two can produce only zero or one.
  • The parity formula encodes both row alternation and within-row alternation.

8. Common mistakes and edge cases

  • Using `(row+col)%2` flips the starting convention and begins with zero.
  • Forgetting that the source uses 1-based indices changes the parity offset.
  • Printing a constant bit in the inner loop loses alternation.
