Inverted numbered right pyramid

Print decreasing row lengths, with every row restarting its number sequence at one.

1. Understand the problem

Given N, print N rows. The first row contains the numbers 1 through N. Each following row contains one fewer number, and every row starts again at 1.

✓ N = 4n = 4
1 2 3 4
1 2 3
1 2
1

The number of entries decreases, but the sequence restarts at one.

✓ N = 1n = 1
1

One row containing one value.

  • N is positive.
  • Row widths are N,N−1,...,1.
  • The value at column j is j, regardless of the row.
What the output requires: Do not use a global counter. The column loop restarts at one for every row.

2. Build the intuition

The outer loop counts down the remaining width. Inside each row, the values still count upward from one. This combines a shrinking shape with a restarting sequence.
💡
Key observation

The outer loop counts down from N to 1; the inner loop counts up from 1 to the current row width.

3. Derive the loop structure

The source method loops i from N down to 1 and prints j from 1 through i.
Row formula
For row width r

Row widths = N,N−1,...,1. Values on a row = 1,2,...,r.

  1. Start the row width at N.
  2. Print the integers 1 through the current row width.
  3. Print a newline.
  4. Decrease the row width by one and repeat until it reaches zero.

4. Java implementation from your DSA repository

This is `nNumberTriangle` from `InvertedNumberedRightPyramid.java`.

public static void nNumberTriangle(int n) {
    for (int rowWidth = n; rowWidth >= 1; rowWidth--) {
        // Restart the column value at one for every row.
        for (int col = 1; col <= rowWidth; col++) {
            System.out.print(col + " ");
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original source is InvertedNumberedRightPyramid.java. The example and dry run follow the method's loop bounds and spacing.

6. Why does this work?

The outer loop visits widths N down to 1 exactly once. For a width r, the inner loop prints every integer from 1 through r. Thus each row has the correct decreasing length and a fresh ascending sequence.

  • The inner loop is reinitialized for each row, so values restart at one.
  • The outer loop decrements by one, so no row width is skipped.

7. Complexity analysis

TIMEO(n²)

The total values printed are N+(N−1)+...+1 = N(N+1)/2.

AUXILIARY SPACEO(1)

Only loop counters and a constant number of scalar variables are used. The printed output is excluded from auxiliary space.

Here n is the input row count. Count the actual emitted positions, including spaces, when deriving the time bound.

8. Common mistakes and edge cases

  • Keeping the value counter outside the inner loop changes the pattern into a continuous sequence.
  • Using rowWidth > 1 omits the final one-value row.
  • Mixing up the row and column counters can make the output increase instead of decrease.
