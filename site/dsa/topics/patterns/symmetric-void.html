Symmetric void pattern

1. Understand the problem

Given N, print two symmetric star blocks with a central gap. In the upper half, each side loses one star per row while the gap widens. In the lower half, the star blocks grow and the gap narrows. The repository implementation prints both halves with N rows each, so the narrowest configuration appears twice.

What the output requires: This differs from the butterfly: the outer star blocks are widest at the first and last rows, while the central void is widest in the middle.

2. Build the intuition

The upper loop starts with N stars on each side and removes one per row. At the same time, the central gap grows by two blank units. The lower loop reverses those counts, starting again with one star per side.
💡
Key observation

Upper half: stars=N−i+1, gap=2i−2. Lower half: stars=i, gap=2(N−i). Each source loop has N iterations, duplicating the narrowest row.

3. Derive the loop structure

Keep upper and lower halves separate because their formulas are easier to understand that way. Print the left star group, then the gap, then the right star group.
Row formula
Upper and lower formulas

Upper row i: N−i+1 stars per side; gap iterations 2i−2. Lower row i: i stars per side; gap iterations 2(N−i). Each gap iteration prints two spaces.

  1. For upper rows i=1..N, print N−i+1 stars on each side.
  2. Print 2i−2 gap iterations between the groups.
  3. For lower rows i=1..N, print i stars on each side.
  4. Print 2(N−i) gap iterations.
  5. Preserve both loops' inclusive bounds to match the source's 2N-row output.

4. Java implementation from your DSA repository

This is `symmetry` from the repository. It intentionally mirrors two N-row loops; the centre configuration is therefore printed twice.

public static void symmetry(int n) {
    // Upper half: star blocks shrink and the void expands.
    for (int row = 1; row <= n; row++) {
        int stars = n - row + 1;
        for (int col = 1; col <= stars; col++) System.out.print("* ");
        for (int gap = 1; gap <= 2 * row - 2; gap++) System.out.print("  ");
        for (int col = 1; col <= stars; col++) System.out.print("* ");
        System.out.println();
    }

    // Lower half: star blocks grow and the void contracts.
    for (int row = 1; row <= n; row++) {
        int stars = row;
        for (int col = 1; col <= stars; col++) System.out.print("* ");
        for (int gap = 1; gap <= 2 * (n - row); gap++) System.out.print("  ");
        for (int col = 1; col <= stars; col++) System.out.print("* ");
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original source is SymmetricVoidPattern.java. The example and dry run follow the method's loop bounds and spacing.

6. Why does this work?

In the upper half, the number of stars on each side decreases by one while the gap increases by two. In the lower half, the star count increases by one while the gap decreases by two. Both sides of every row use the same star count, preserving horizontal symmetry. The two loops each include their boundary row, producing the stated duplicated centre configuration.

  • Upper and lower formulas are reverses of one another.
  • The central gap is non-negative in both loops.
  • The duplicated narrow row follows directly from both loops including their first/last boundary.

7. Complexity analysis

TIMEO(n²)

8. Common mistakes and edge cases

  • Assuming the source prints 2N−1 rows; it prints 2N.
  • Changing the lower loop to start at two removes the duplicate but no longer matches the repository source.
  • Forgetting that each star itself is followed by a space changes the apparent gap width.
