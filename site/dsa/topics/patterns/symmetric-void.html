Symmetric void pattern

Print two equal star groups on every row, with a central gap that expands and then contracts.

1. Problem definition

Given a positive integer N, print a symmetric void pattern containing exactly 2N rows. Each row consists of two equal groups of asterisks (*) separated by a central gap.

The pattern must follow these rules:

  1. In the first half, print N rows. Start with N stars in each group and decrease the number of stars by one in each subsequent row.
  2. As the groups shrink, increase the central gap by two gap iterations per row. Each gap iteration prints two spaces.
  3. In the second half, print another N rows. Start with one star in each group and increase the number of stars by one in each subsequent row.
  4. Decrease the central gap by two gap iterations per row until the final row has no central gap iterations.
  5. Print both halves completely. Therefore, the narrowest row (one star in each group with the widest gap) appears twice consecutively.

  • Output: The described pattern, with 2N rows.

Important source detail: Both loops execute from 1 through N. Do not remove either boundary row: doing so would change the source's output from 2N rows and remove the duplicated narrowest row.

2. Build the intuition

Think of every row as three consecutive parts: a left star group, a central gap, and a right star group. The left and right groups always contain the same number of stars.

💡
Key observation

Only two values change from row to row: the number of stars in each group and the number of central-gap iterations. The upper half decreases the first and increases the second; the lower half reverses both changes.

For N = 3, the number of stars in each group follows 3, 2, 1, 1, 2, 3. The gap iterations follow 0, 2, 4, 4, 2, 0. These sequences make the vertical symmetry explicit.

3. Derive the loop structure

Use two separate outer loops. Keeping the halves separate makes the changing counts straightforward and matches the original implementation.

Row formulas
Upper half · row i, from 1 to N

Stars in each group: N - i + 1
Gap iterations: 2i - 2

Lower half · row i, from 1 to N

Stars in each group: i
Gap iterations: 2(N - i)

Each star iteration prints "* "; each gap iteration prints " ".

  1. For each upper-half row, calculate N - i + 1 and print that many stars on the left.
  2. Print 2i - 2 gap iterations, then print the same number of stars on the right.
  3. For each lower-half row, print i stars on the left.
  4. Print 2(N - i) gap iterations, then print i stars on the right.
  5. After each pair of star groups, print a newline.

4. Java implementation from your DSA repository

This is the repository's symmetry(int n) method. The interactive test-case input in main is omitted; the pattern-generation logic and loop bounds are preserved.

public static void symmetry(int n) {
    // Upper half: star groups shrink and the central gap expands.
    for (int i = 1; i <= n; i++) {
        int stars = n - i + 1;

        // Left star group.
        for (int j = 1; j <= stars; j++) {
            System.out.print("* ");
        }

        // Central gap.
        for (int j = 1; j <= 2 * i - 2; j++) {
            System.out.print("  ");
        }

        // Right star group.
        for (int j = 1; j <= stars; j++) {
            System.out.print("* ");
        }

        System.out.println();
    }

    // Lower half: star groups grow and the central gap contracts.
    for (int i = 1; i <= n; i++) {
        int stars = i;

        // Left star group.
        for (int j = 1; j <= stars; j++) {
            System.out.print("* ");
        }

        // Central gap.
        for (int j = 1; j <= 2 * (n - i); j++) {
            System.out.print("  ");
        }

        // Right star group.
        for (int j = 1; j <= stars; j++) {
            System.out.print("* ");
        }

        System.out.println();
    }
}

6. Why does this work?

Every row is horizontally symmetric because the algorithm prints the same number of stars before and after the central gap.

  • Upper half: For i = 1..N, the star count per side is N - i + 1, which decreases from N to 1. The gap count 2i - 2 increases from 0 to 2N - 2.
  • Lower half: For i = 1..N, the star count per side is i, which increases from 1 to N. The gap count 2(N - i) decreases from 2N - 2 to 0.
  • Vertical symmetry: The lower-half sequence is the reverse of the upper-half sequence. Both loops include their boundary configuration, so the narrowest row appears twice.
  • Termination: Each outer loop executes exactly N times, and every inner loop has a finite bound for N ≥ 1.

Therefore, the algorithm prints exactly the required 2N rows, with equal star groups and a central gap that expands and contracts symmetrically.

7. Complexity analysis

TIMEO(N²)

There are 2N rows. Each row prints O(N) stars and spaces, so the total number of printed characters is Θ(N²).

AUXILIARY SPACEO(1)

The method uses only loop counters and a constant number of integer variables. The output itself is not counted as auxiliary space.

The time complexity is measured against the total output size, including the spaces printed between the star groups.

8. Common mistakes and edge cases

  • Printing only 2N−1 rows: Starting the lower loop at 2 removes the repeated narrowest row and no longer matches this source implementation.
  • Using the wrong gap formula: The upper half uses 2i - 2; the lower half uses 2(N - i).
  • Making the two star groups different: Both groups must use the same star count on every row.
  • Confusing gap iterations with literal spaces: One gap iteration prints two spaces. Also, each star is printed with a following space.
  • Smallest input: For N = 1, both loops still execute once, so the output contains two identical rows.

Remember: For symmetric patterns built from two loops, inspect both loop boundaries carefully. They determine whether the centre row or centre configuration is printed once or twice.
