Number crown pattern

Print an increasing number sequence and its reverse on each row, separated by a shrinking central gap.

1. Understand the problem

Given N, print N rows. Row i contains 1 through i on the left, a central gap, and i through 1 on the right. The gap becomes smaller on each row until the two halves meet.

✓ N = 3n = 3
1             1
1 2         2 1
1 2 3 3 2 1

The central gap shrinks to zero on the final row.

✓ N = 1n = 1
1 1

The two one-value halves meet immediately.

  • N is positive.
  • Each side contains i numbers on row i.
  • The source prints two spaces for every central-gap iteration.
What the output requires: There are three regions per row: an increasing sequence, a central gap, and a decreasing sequence.

2. Build the intuition

The two number groups are mirror images. The left loop counts up from one to i. The right loop counts down from i to one. The only changing space is the gap between them.
💡
Key observation

The left and right groups each contain i values. The number of gap iterations is 2(N−i), so the gap closes as i approaches N.

3. Derive the loop structure

Use three loops for the three visible regions. Do not try to calculate the right sequence by reversing the entire output string; simply count down from the row index.
Row formula
For row i

Left values = 1..i; gap iterations = 2(N−i), each printing two spaces; right values = i..1.

  1. Iterate row i from 1 through N.
  2. Print the left sequence from 1 through i, with a space after each number.
  3. Print two spaces for each of 2(N−i) gap iterations.
  4. Print the right sequence from i down to 1.
  5. Finish the row.

4. Java implementation from your DSA repository

This is `numberCrown` from the repository. Its middle gap loop prints two spaces per iteration; the code preserves that alignment convention.

public static void numberCrown(int n) {
    for (int row = 1; row <= n; row++) {
        // Left half: 1 up to the current row number.
        for (int col = 1; col <= row; col++) {
            System.out.print(col + " ");
        }
        // The gap closes by two iterations on every next row.
        for (int gap = 1; gap <= 2 * (n - row); gap++) {
            System.out.print("  ");
        }
        // Right half: mirror the left sequence.
        for (int col = row; col >= 1; col--) {
            System.out.print(col + " ");
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original source is NumberCrownPattern.java. The example and dry run follow the method's loop bounds and spacing.

5. Dry run: n = 3

The left and right sequences grow by one value each row. The central gap loses two iterations per row.

RowLeading spacesSymbols / valuesInner gapResult
1—1 | 14 iterations1 ... 1
2—1,2 | 2,12 iterations1 2 ... 2 1
3—1,2,3 | 3,2,101 2 3 3 2 1

At row 3, the gap loop does not execute. The two sequences meet directly, and the middle value 3 appears on both sides because each half includes the row number.

6. Why does this work?

For row i, the first loop emits exactly 1..i and the final loop emits i..1. Both halves have equal length and mirror one another. The middle loop executes 2(N−i) times, which is non-negative and decreases to zero at the last row. Therefore the pattern converges symmetrically.

  • The left and right sequences are reverses of each other.
  • The gap count is zero at i=N, so no negative or extra gap is printed.

7. Complexity analysis

TIMEO(n²)

Each row prints 2i numbers plus O(N−i) spaces; summed over N rows, the output size is Θ(N²).

AUXILIARY SPACEO(1)

Only loop counters and a constant number of scalar variables are used. The printed output is excluded from auxiliary space.

Here n is the input row count. Count the actual emitted positions, including spaces, when deriving the time bound.

8. Common mistakes and edge cases

  • Starting the right sequence at i−1 omits the duplicated peak value that the source includes.
  • Printing only one space per gap iteration changes the intended alignment.
  • The gap must use N−row, not row−1; it shrinks as the row grows.
