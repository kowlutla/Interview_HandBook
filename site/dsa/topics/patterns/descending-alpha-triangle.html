Descending alphabet triangle

Print rows that start at the N-th letter and move backward toward A.

1. Understand the problem

Given N, print N rows. Every row starts at the N-th uppercase letter. Row i contains i letters in descending alphabet order.

✓ N = 4n = 4
D
D C
D C B
D C B A

Every row begins with D; later rows extend farther toward A.

✓ N = 1n = 1
A

The only row begins and ends at A.

  • 1 ≤ N ≤ 26.
  • The first character on every row is 'A'+N−1.
  • Row i contains i letters.
What the output requires: Do not restart at A on each row. The first letter is determined by N and stays fixed; the column moves backward through the alphabet.

2. Build the intuition

Find the last letter once from N. On every row, begin at that letter and decrement the character after printing each position. Longer rows simply continue farther toward A.
💡
Key observation

The printed character at column j is 'A'+N−j. The row index controls how many of these descending characters are shown.

3. Derive the loop structure

The source initializes `c` to the N-th letter at the start of each row, then decrements it after each printed character.
Row formula
For row i and column j

Starting character = 'A'+N−1. Character at column j = 'A'+N−j. Columns = 1..i.

  1. Validate that N is between 1 and 26.
  2. For each row i, initialize ch to 'A'+N−1.
  3. Print i characters, decrementing ch after each one.
  4. Move to the next row and reset ch to the same starting letter.

4. Java implementation from your DSA repository

This is `alphaTriangle` from the source. The character is reset to the N-th letter for every row.

public static void alphaTriangle(int n) {
    for (int row = 1; row <= n; row++) {
        // Every row starts from the same final alphabet character.
        char ch = (char) ('A' + n - 1);
        for (int col = 1; col <= row; col++, ch--) {
            System.out.print(ch + " ");
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original source is AlphaTrianglePattern.java. The example and dry run follow the method's loop bounds and spacing.

5. Dry run: n = 4

The starting character is D on every row. The inner loop decrements it after each printed character.

3—D,C,B—D C B

The first row contains only D; the final row contains the complete descending sequence D,C,B,A.

6. Why does this work?

At the beginning of every row, the character is reset to the N-th letter. Each inner iteration prints the current character and decrements it. Therefore row i prints the first i characters of the same descending sequence.

  • Resetting ch in the outer loop ensures every row starts at the same letter.
  • The inner loop's i iterations determine the row length.

8. Common mistakes and edge cases

  • Initializing the character from the row index changes the starting character on each row.
  • Incrementing instead of decrementing prints ascending letters.
  • N must not exceed 26 if the pattern is restricted to A–Z.
