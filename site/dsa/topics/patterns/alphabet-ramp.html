Alphabet ramp pattern

Print the row's alphabet letter repeatedly, with one additional copy on each row.

1. Understand the problem

Given N, print N rows. Row i contains i copies of the i-th uppercase letter: A on row one, B on row two, and so on.

✓ N = 4n = 4
A
B B
C C C
D D D D

The character changes between rows; it does not change within a row.

✓ N = 1n = 1
A

One copy of A.

  • 1 ≤ N ≤ 26 for uppercase English letters.
  • Row i contains i characters.
  • All characters on one row are identical.
What the output requires: This is different from the increasing letter triangle: the letter is fixed within a row and changes only when the outer loop advances.

2. Build the intuition

The outer loop already tells us which alphabet letter to use. Convert row i to 'A'+i−1, then print that same character i times.
💡
Key observation

Use the row index for the character expression and for the inner-loop bound. Do not use the column index as the printed value.

3. Derive the loop structure

For each row, calculate its character once, then repeat it in the inner loop.
Row formula
For row i

Character = 'A'+i−1. Repetition count = i.

  1. Iterate row i from 1 through N.
  2. Compute the row character as 'A'+i−1.
  3. Print that character i times.
  4. Print newline.

4. Java implementation from your DSA repository

This is `alphaRamp` from the source. The row character is computed inside the outer loop and remains unchanged throughout the inner loop.

public static void alphaRamp(int n) {
    for (int row = 1; row <= n; row++) {
        char ch = (char) ('A' + row - 1);
        // Repeat the row's character exactly row times.
        for (int col = 1; col <= row; col++) {
            System.out.print(ch + " ");
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original source is AlphaRampPattern.java. The example and dry run follow the method's loop bounds and spacing.

5. Dry run: n = 4

At each outer-loop iteration, the character changes once. The inner loop repeats that fixed character.

RowLeading spacesSymbols / valuesInner gapResult
1—A × 1—A
2—B × 2—B B
3—C × 3—C C C
4—D × 4—D D D D

The number of printed letters is 1+2+3+4 = 10. Each row has only one distinct character.

6. Why does this work?

At row i, the expression 'A'+i−1 selects the i-th uppercase letter. The inner loop executes i times and prints the unchanged character. Thus row i contains exactly i copies of its corresponding letter.

  • The row character is initialized once per row, not once per column.
  • The inner-loop bound equals the row index, giving the required repetition count.

7. Complexity analysis

TIMEO(n²)

The number of printed characters is N(N+1)/2.

AUXILIARY SPACEO(1)

Only loop counters and a constant number of scalar variables are used. The printed output is excluded from auxiliary space.

Here n is the input row count. Count the actual emitted positions, including spaces, when deriving the time bound.

8. Common mistakes and edge cases

  • Printing the column character creates an increasing letter triangle.
  • Incrementing the character inside the inner loop changes the repeated sequence.
  • N above 26 is outside the A–Z contract.
