Centered star pyramid

Print a centred pyramid with N rows; each row gains two stars and loses one leading space.

1. Understand the problem

Given N, print a centred pyramid of N rows. The first row contains one star. Each following row adds two stars, and the base contains 2N−1 stars.

✓ N = 4n = 4
   *   \n  ***  \n ***** \n*******

The pyramid expands evenly around its centre.

✓ N = 1n = 1
*

One row forms the apex and base.

  • N is positive.
  • The number of stars on row i is 2i−1.
  • The source prints N−i leading spaces and N−i trailing spaces.
What the output requires: The leading indentation decreases by one per row while the star count increases by two. Trailing spaces do not affect the visible shape.

2. Build the intuition

A centred pyramid must expand on both sides of a fixed centre line. The odd sequence 1, 3, 5, ... gives a single centre star and then adds one star on each side. The spaces shift the left edge left as the row grows.
💡
Key observation

The number of stars is always odd: 2i−1. The leading spaces are N−i, so the centre stays aligned.

3. Derive the loop structure

For each row, print the indentation first, then the odd number of stars. The source also prints trailing spaces equal to the leading indentation.
Row formula
For row i

Leading spaces = N−i; stars = 2i−1; trailing spaces = N−i.

  1. Iterate i from 1 through N.
  2. Print N−i spaces.
  3. Print stars for j = 1 through 2i−1.
  4. Print N−i trailing spaces, matching the source output.
  5. Print newline.

4. Java implementation from your DSA repository

This is `nStarTriangle` from the source. The separate loops make the three regions—left padding, stars and right padding—explicit.

public static void nStarTriangle(int n) {
    for (int row = 1; row <= n; row++) {
        // Move the first star toward the left as the pyramid grows.
        for (int space = 1; space <= n - row; space++) {
            System.out.print(" ");
        }
        // An odd number of stars keeps the row centred.
        for (int star = 1; star < 2 * row; star++) {
            System.out.print("*");
        }
        // The source prints matching trailing spaces.
        for (int space = 1; space <= n - row; space++) {
            System.out.print(" ");
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original Java source is available at StarPyramid.java. The example above and the dry run below follow this method's loop bounds and spacing.

6. Why does this work?

On row i, the method emits N−i leading spaces and 2i−1 stars. The left indentation decreases by one while the odd-width star region grows by two, adding one star to each side of the centre. This preserves a common centre line and produces N rows.

  • At i=1, the row has one star and N−1 leading spaces.
  • At i=N, indentation is zero and the base has 2N−1 stars.
  • The row's star count is odd for every i, so there is a centre position.

7. Complexity analysis

TIMEO(n²)

Across all rows, the star count sums to N². The leading and trailing padding also sum to Θ(N²) in the source method.

AUXILIARY SPACEO(1)

Only loop counters and a constant number of scalar variables are used. The printed output is not counted as auxiliary storage.

Here n is the input row count. Count the actual emitted positions (including spaces) when deriving the bound; the running time is proportional to the output size.

8. Common mistakes and edge cases

  • Using 2*i stars produces an even-width row and shifts the centre.
  • Using N−row+1 spaces leaves the pyramid one column too far right.
  • For exact-output comparison, be aware the source emits trailing spaces.
  • The newline belongs after the trailing-space loop.
