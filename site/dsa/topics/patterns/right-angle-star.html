Right-angle star triangle

Print a left-aligned right-angle triangle whose row i contains i stars.

1. Understand the problem

Given N, print N rows. The first row contains one star, the second contains two, and row i contains exactly i stars. The triangle is left-aligned.

✓ N = 4n = 4
*
* *
* * *
* * * *

Each row adds one star.

✓ N = 1n = 1
*

One row with one star.

  • N is positive.
  • The number of rows is N.
  • The row width grows from 1 to N.
  • The source prints a space after each star.
What the output requires: For row i, print i stars. There is no leading indentation because the left edge is fixed.

2. Build the intuition

The row number already tells us how many stars to print. Row 1 needs one, row 2 needs two, and so on. The outer loop controls the row number; the inner loop counts from 1 to that row number.
💡
Key observation

The inner-loop upper bound is the current row index i, not N. This is what makes the right edge grow.

3. Derive the loop structure

Use two nested loops. The outer loop visits rows 1 through N. For row i, the inner loop emits i stars and then the outer loop prints a newline.
Row formula
For row i

Stars = i; leading spaces = 0; inner gap = none. Total stars = 1 + 2 + ... + N.

  1. Iterate row from 1 through N.
  2. For each row, iterate col from 1 through row.
  3. Print one star for each column.
  4. Move to the next line after the inner loop finishes.

4. Java implementation from your DSA repository

This is the `printPattern` method from the source, with comments clarifying why the inner loop ends at the current row.

public static void printPattern(int n) {
    for (int row = 1; row <= n; row++) {
        // Row i contains i stars.
        for (int col = 1; col <= row; col++) {
            System.out.print("* ");
        }
        System.out.println();
    }
}

This is the core pattern method, separated from the original console-driven test-case wrapper. The original Java source is available at RightAngleTriangle.java. The example above and the dry run below follow this method's loop bounds and spacing.

5. Dry run: n = 4

Track the row index and the inner-loop count. The inner loop resets for every new row but its upper bound increases.

The total number of stars is 1+2+3+4 = 10. In general, the count is N(N+1)/2.

6. Why does this work?

For each row i, the inner loop executes exactly i times, so it prints exactly i stars. The outer loop visits every row from 1 to N once. Therefore the output has the required row widths and no row is skipped.

  • The row index is the loop invariant that determines the current row width.
  • The newline is outside the inner loop, so all stars for a row stay on one line.

7. Complexity analysis

TIMEO(n²)

The method emits 1+2+...+N = N(N+1)/2 stars, which is Θ(N²).

AUXILIARY SPACEO(1)

Only loop counters and a constant number of scalar variables are used. The printed output is not counted as auxiliary storage.

Here n is the input row count. Count the actual emitted positions (including spaces) when deriving the bound; the running time is proportional to the output size.

8. Common mistakes and edge cases

  • Using `col <= n` prints a square instead of a triangle.
  • Printing newline inside the inner loop breaks each row into separate lines.
  • The inner loop must restart at 1 for each row.
