Isomorphic Strings

Determine whether two strings have the same character structure, even when their actual characters are different.

1. Understand the problem

We are given two strings of equal length. We need to decide whether we can replace every character in the first string with a character in the second string so that the strings become identical.

The replacement must be consistent. If p becomes t once, every later p must also become t. The mapping must also be one-to-one: two different characters from the first string cannot share the same replacement character.

✓ Isomorphic"egg" → "add"

e → a and g → d. The repeated-character structure is preserved.

✕ Not isomorphic"foo" → "bar"

The two o characters would need to map to both a and r.

✕ Not isomorphic"ab" → "aa"

Both a and b would map to the same target a.

✓ Isomorphic"paper" → "title"

p → t, a → i, e → l, r → e.

What matters: The letters themselves do not matter. The positions at which characters repeat must have the same structure in both strings.

2. Build the intuition

Take str1 = "paper" and str2 = "title". Compare the characters at each position and record a mapping in both directions.

When the first p is paired with t, the method records both directions: p → t and t → p. When the pair appears again at index 2, both stored mappings agree, so processing can continue.

With "foo" and "bar", the first pair records f → b and b → f. At the next position, o has no mapping but a is already mapped from b. The new pair conflicts with the reverse mapping and is rejected.

💡
The key observation

A one-way mapping is not enough. Store the mapping in both directions so that one source character cannot map to multiple targets and multiple source characters cannot map to the same target.

3. How your implementation stores the mapping

Your Java file uses two integer arrays of size 256. count1[c1] stores the character mapped from str1 to str2; count2[c2] stores the reverse mapping. Both arrays are initialized to -1 to represent an unmapped character.

Mapping state
Forward and reverse checks

For each pair (c1, c2), create both mappings only when both entries are still -1. Otherwise, verify that count1[c1] == c2 and count2[c2] == c1. If either check fails, return false.

4. Java implementation from your DSA repository

This is the method in IsomorphicStrings.java. It first checks equal lengths, then uses two 256-element arrays to store the forward and reverse character mappings. An entry of -1 means no mapping has been assigned yet.

public static boolean areIsomorphic(String str1, String str2) {
    // Isomorphic strings must have the same length.
    if (str1.length() != str2.length()) {
        return false;
    }

    // count1[c1] stores c1 -> c2; count2[c2] stores the reverse c2 -> c1.
    int[] count1 = new int[256];
    int[] count2 = new int[256];

    // -1 means that this character does not have a mapping yet.
    Arrays.fill(count1, -1);
    Arrays.fill(count2, -1);

    // Process the two strings at the same index.
    for (int i = 0; i < str1.length(); i++) {
        char c1 = str1.charAt(i); // Current character from the first string.
        char c2 = str2.charAt(i); // Character it must map to in the second string.

        // If neither character is mapped, create the mapping in both directions.
        if (count1[c1] == -1 && count2[c2] == -1) {
            count1[c1] = c2; // Record the forward mapping: c1 -> c2.
            count2[c2] = c1; // Record the reverse mapping: c2 -> c1.
        } else if (count1[c1] != c2 || count2[c2] != c1) {
            // Either direction conflicts with an earlier mapping.
            return false;
        }
    }

    // Every character pair respected the same one-to-one mapping.
    return true;
}

The source file imports java.util.Arrays. Because the arrays have 256 entries, every input character must have a numeric char value from 0 to 255; larger values can cause ArrayIndexOutOfBoundsException. The method also assumes non-null inputs and does not validate them.

See where it fails: For s = "ab" and t = "aa", index 0 matches and stores position 0 for both a characters. At index 1, b has never appeared (-1), but a last appeared at 0. The mismatch immediately returns false.

6. Why is this correct?

Invariant: After processing each pair of characters, every mapping recorded in count1 and count2 agrees with all pairs seen so far.

  • Neither character has a mapping: The pair is new in both directions, so recording c1 → c2 and c2 → c1 preserves a one-to-one relationship.
  • A mapping already exists: Both directions must match the current pair. If either direction differs, the mapping is inconsistent and the method returns false.
  • The scan completes: Every position respected the same forward and reverse mappings. Therefore the character substitution is consistent and one-to-one.

The reverse array is essential: it prevents two different characters in the first string from being mapped to the same character in the second string.

7. Complexity analysis

TIMEO(n)

Two fixed arrays of 256 elements are initialized, then the method scans the n character pairs once.

AUXILIARY SPACEO(1)

The two arrays always contain 256 integers each, regardless of input length.

More precisely, initialization costs O(256) and scanning costs O(n), so total time is O(256 + n), which simplifies to O(n) because 256 is constant.

8. Common mistakes and edge cases

  • Using only a forward map. It accepts "ab" → "aa", even though two source characters collide on one target.
  • Comparing character frequencies only. Frequency counts ignore order. The positions of repeated characters are what matter.
  • Assuming every Java character fits in 256 slots. That is safe only under a stated byte/ASCII constraint, not for all Java char values.
  • Using only one mapping direction. The reverse array is necessary to prevent two source characters from mapping to the same target character.
  • Ignoring input assumptions. This implementation uses arrays of length 256, so input characters must fit in the range 0–255. The method also expects non-null strings.
